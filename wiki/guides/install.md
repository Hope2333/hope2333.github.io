# 安装指引

各项目的安装方式取决于是否已进入 hope2333 软件源。

## 已入源项目（pacman）

已入源的项目优先用 pacman 安装，以 codegraph 为例：

```sh
pacman -Sy codegraph
```

`-Sy` 会先刷新软件源再安装，确保拿到最新版本。更多仓库将陆续入源。

## 未入源项目（GitHub 手动安装）

尚未入源的项目，请前往对应项目的 GitHub 仓库获取，安装方式见仓库 README。各项目的仓库链接见 [项目索引](../index.md)。

## 验证安装

安装完成后，可通过 `--version` 参数验证，能正常输出版本号即安装成功。
