# codegraph-termux

> Local-first code intelligence for AI agents (MCP)

## 简介

Local-first code intelligence for AI agents（MCP）。项目为 AI 代理提供本地优先的代码智能能力，通过 MCP 协议接入，代码索引与分析都在本地完成。

## 安装

该项目已进入 hope2333 软件源，在 Termux 中执行：

```sh
pacman -Sy codegraph
```
