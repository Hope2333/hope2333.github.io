# Push261005 — rc1：fleet B 线重建代（-90，raw 原包）

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261005) · [English](../../release/Push261005.md)

## 概览

**Push261005** 是 native 家族的整代重建（fleet B 线，**NDK r27c / 不 strip**），pkgrel **`-90`**。本代与旧 transplant 代**不同源**——上游版本号相同，工具链谱系换新。native deb 亦已按此代全量重打。

**57 件**：28 pacman + 28 deb + `SHA256SUMS.txt`

| 家族 | 版本范围 | 数量（pacman + deb） |
|------|----------|----------------------|
| `opencode`（v2 native） | 2.0.0 – 2.0.22 | 23 + 23 |
| `opencode1`（v1 native） | 1.18.30 – 1.18.34 | 5 + 5 |

**本批为 raw 未压缩原包**——UPX 压制外包，**compressed 族后续产出后上传到同一 tag**（一个滚动批次一个 tag）。wrapper 族 / glibc 族 / compressed 族**不在本批内**。

**同代互斥**：同代内 native / wrapper / compressed 三选一；跨代 v1（`opencode1*`）与 v2（`opencode*`）可共存；`*-standalone` 为共存例外。

## 安装

```bash
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

pacman -S opencode     # v2 主线（本批 = -90 重建代，raw）
pacman -S opencode1    # v1 主线（与 v2 共存）
```

手动钉版：`pacman -U opencode-2.0.22-90-aarch64.pkg.tar.xz`
