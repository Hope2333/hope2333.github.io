# Push260906 — 正式发布

三家族 × 双格式包列车。取代 Push260903。

## 新变化

- 13 版（1.18.15–1.18.27）× 3 家族 × 2 格式 = 78 包
- 原生主线：纯 Bionic、零 glibc、seccomp SIGSYS shim、TUI、bin-direct
- glibc 附录：bin-only 打包（单二进制、无维护者钩子），自包含复合体（无需 Termux glibc 系包）
- 压缩家族：UPX 压制运行时、gzip 快速包装包、恒带 `libopencode-crhandler.so`
- UPX 运行时资产：`opencode-native-<ver>-upx.xz`（13 个）
- SHA256SUMS.txt 共 91 项校验条目
- Lasted：v1.18.27

## 安装

```bash

pacman -S opencode

# glibc
pacman -S opencode-glibc

# 压缩
pacman -S opencode-compressed
```
