# Push260928 — RC4 修复与补全

[GitHub Release（英文版）](https://github.com/Hope2333/opencode-termux/releases/tag/Push260928)

## 概览

RC4 = RC3 双代家族的**修正与补全**，共 **84 件计划资产**（另有 repo db/mirrorlist 4 件由 site-rebuild 自愈回传）：

- **seccomp shim 全线随包**（修复 #17/#24：kernel 4.19 等老内核 `Bad system call`）——v2 native 全线 **PKGREL=4**，`harden-native` 接入 `family-v2-native` 链
- **PTY 助手换用上游官方 musl 全静态变体**（修复 #27：glibc ABI 无法在 bionic 加载）——构建后逐版嵌入哈希断言
- **区间补齐**：新增 v2.0.13–2.0.17（B 线）与 v1.18.33（A 线）
- **stale-serve-kill 安装钩子**仅随 v2 2.0.[0-3]（packaging hook 注册表：`HOOKS_ENABLE` / `HOOKS_DISABLE` + 版本区间默认；实测 2.0.0 发射 / 2.0.5 不发射）

| Family | 代际 | 包名 | 格式 | 说明 |
|--------|------|------|------|------|
| native（主线） | v2 | `opencode` | deb + pacman `.pkg.tar.xz` | 零 glibc bionic ELF；PKGREL=4，shim + musl pty 内嵌 |
| native（主线） | v1 | `opencode1` | deb + pacman `.pkg.tar.xz` | 零 glibc bionic ELF，直跑 |
| wrapper（附录） | v2 | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | bun-termux-loader wrap |
| wrapper（附录） | v1 | `opencode1-wrapper` | deb + pacman `.pkg.tar.xz` | glibc runtime payload |
| compressed（压制） | v1 | `opencode1-compressed` | deb + pacman `.pkg.tar.gz` | UPX 外包压制（见 opencode-compressed-branch） |

**互斥关系（双代口径）**：跨代 `opencode1`（v1）与 `opencode`（v2）**可双装共存**；同代 native / wrapper / compressed **三选一**。

版本覆盖：v2 native 19 版（2.0.0–2.0.18）/ v2 wrapper 19 版（2.0.0–2.0.18）/ v1 native 4 版（1.18.30–33）/ v1 wrapper、compressed 各 3 版（1.18.30–32）。

## Install

### 软件源配置（一次性）

```bash
# 一键：配置源并安装（pacman + apt 源一并就位）
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode
```

### 软件源安装（apt / pacman，双代共存）

```bash
# v2 主线
pacman -S opencode            # 或 opencode-wrapper
apt update && apt install opencode
# v1 主线（与 v2 共存）
pacman -S opencode1           # 或 opencode1-wrapper / opencode1-compressed
apt update && apt install opencode1
```

### 手动安装（指定版本）

```bash
pacman -U opencode-2.0.18-4-aarch64.pkg.tar.xz              # v2 native（PKGREL=4，含 shim）
pacman -U opencode1-1.18.33-3-aarch64.pkg.tar.xz            # v1 native（PKGREL=3）
pacman -U opencode1-compressed-1.18.32-3-aarch64.pkg.tar.gz # v1 compressed（注意 .gz）
dpkg -i opencode_2.0.18_aarch64.deb
dpkg -i opencode1_1.18.33_aarch64.deb
```

> deb 无 pkgrel 概念（--clobber 覆盖）；v2 native pac 产物名带 `-4-`，其余族 `-3-`。
