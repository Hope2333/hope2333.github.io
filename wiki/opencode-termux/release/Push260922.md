# Push260922 — RC3 Two-Generation Full-Family Refresh

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260922)

## Overview

RC3 clean-slate rebuild: the original 69 assets of Push260922 were purged and the
full two-generation family was rebuilt and re-uploaded with **PKGREL=3** (third
release marker) — **70 planned assets** in total (plus repo db/mirrorlist
self-healed back by site-rebuild). The old crash-prone bun-1.4.2-era builds and
stale packages are gone in one sweep; everything was built from the latest HEAD
of the repository.

| Family | Generation | Package | Format | Notes |
|--------|-----------|---------|--------|-------|
| native (mainline) | v2 | `opencode` | deb + pacman `.pkg.tar.xz` | Zero-glibc bionic ELF, direct exec |
| native (mainline) | v1 | `opencode1` | deb + pacman `.pkg.tar.xz` | Zero-glibc bionic ELF, direct exec |
| wrapper (appendix) | v2 | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | bun-termux-loader wrap |
| wrapper (appendix) | v1 | `opencode1-wrapper` | deb + pacman `.pkg.tar.xz` | glibc runtime payload |
| compressed (UPX) | v1 | `opencode1-compressed` | deb + pacman `.pkg.tar.gz` | UPX outsourced (see opencode-compressed-branch) |

**Mutual exclusion**: across generations `opencode1` (v1) and `opencode` (v2) CAN
coexist side by side; within the same generation install exactly ONE of
native / wrapper / compressed.

Version coverage: v2 native & wrapper 13 versions each (2.0.0–2.0.12) +
v1 three families × 3 versions (1.18.30–32).

## Install

### Configure the software source (once)

```bash
# One-liner: configure sources and install (pacman + apt in one go)
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode
```

### Install from the software source (apt / pacman, two generations coexist)

```bash
# v2 mainline
pacman -S opencode            # or opencode-wrapper
apt update && apt install opencode
# v1 mainline (coexists with v2)
pacman -S opencode1           # or opencode1-wrapper / opencode1-compressed
apt update && apt install opencode1
```

### Manual install (pinned version)

```bash
pacman -U opencode-2.0.12-3-aarch64.pkg.tar.xz              # v2 native (PKGREL=3)
pacman -U opencode1-1.18.32-3-aarch64.pkg.tar.xz            # v1 native (PKGREL=3)
pacman -U opencode1-compressed-1.18.32-3-aarch64.pkg.tar.gz # v1 compressed (note .gz)
dpkg -i opencode_2.0.12_aarch64.deb
dpkg -i opencode1_1.18.32_aarch64.deb
```

> deb has no pkgrel concept — Version unchanged (--clobber overwrite); pac
> artifacts carry `-3-` in the filename.
