# Push261005 — rc1: fleet B-line rebuild (-90, raw)

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261005) · [中文](../../zh_CN/release/Push261005.md)

## Overview

**Push261005** is a full **rebuild generation** of the native families on the
fleet B line (**NDK r27c, not stripped**), pkgrel **`-90`**. This generation is
**not** the same source as the older transplant-generation packages — same
upstream versions, new toolchain lineage. All native debs were repacked from
this generation as well.

**57 assets**: 28 pacman + 28 deb + `SHA256SUMS.txt`

| Family | Versions | Count (pacman + deb) |
|--------|----------|----------------------|
| `opencode` (v2 native) | 2.0.0 – 2.0.22 | 23 + 23 |
| `opencode1` (v1 native) | 1.18.30 – 1.18.34 | 5 + 5 |

**This batch is raw (uncompressed) packages only** — the UPX pressing is
outsourced. The **compressed family will be produced later and uploaded to
this same tag** (one rolling batch, one tag). The wrapper / glibc /
compressed families are **not** part of this batch.

**Mutual exclusion**: within one generation pick exactly ONE of native /
wrapper / compressed; v1 (`opencode1*`) and v2 (`opencode*`) coexist;
`*-standalone` is the coexistence exception.

## Install

```bash
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

pacman -S opencode     # v2 mainline (this batch = -90 rebuild, raw)
pacman -S opencode1    # v1 mainline (coexists with v2)
```

Manual (pinned): `pacman -U opencode-2.0.22-90-aarch64.pkg.tar.xz`
