# Push260912 — opencode-wrapper Formal Release

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260912)

## Overview

Rolling Push tag cycle completes the **`opencode-glibc` → `opencode-wrapper` rename** and fills out the four-family matrix. Version **v1.18.30**.

| Family | Package Name | Format | Description |
|--------|-------------|--------|-------------|
| native (mainline) | `opencode` | deb + pacman `.pkg.tar.xz` | Zero-glibc bionic ELF, runs directly |
| wrapper (appendix) | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | Glibc wrapper — renamed from `opencode-glibc` |
| compressed (packed) | `opencode-compressed` | deb + pacman `.pkg.tar.gz` | UPX --best packed |
| standalone (rollback) | `opencode-wrapper-standalone` | deb + pacman `.pkg.tar.xz` | Frozen single-version rollback, coexists with `opencode` |

Also ships `SHA256SUMS.txt` (full verification) and `Packages.gz` (apt flat source index).

## Package Rename: opencode-glibc → opencode-wrapper

The glibc appendix family is renamed to `opencode-wrapper`:

- **deb**: `Replaces: opencode-glibc` + `Breaks: opencode-glibc (<< version)` — existing `opencode-glibc` users **upgrade automatically** to `opencode-wrapper`, no manual action needed.
- **pacman**: `replaces=('opencode-glibc')` — same automatic upgrade semantics.

**Mutual exclusion**: `opencode` ↔ `opencode-wrapper` are mutually exclusive; `opencode-compressed` Provides `opencode`, so only one of the three may be installed. `opencode-wrapper-standalone` is mutually exclusive with `opencode-wrapper`, but coexists with `opencode` (rollback path only).

## Install

### Source Configuration (one-time)

```bash
# One-shot: configure sources and install (pacman + apt sources ready)
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

# Or manual:
# pacman — append unified [hope2333] section to $PREFIX/etc/pacman.conf (full block at
#   /repo/Termux/ manual config block), then pacman -Sy && pacman -S hope2333-mirrorlist
#   (post-install hook converges the section to section-header + Include form)
# apt — write to $PREFIX/etc/apt/sources.list.d/hope2333.list:
#   deb [trusted=yes arch=aarch64] https://github.com/Hope2333/opencode-termux/releases/latest/download/ ./
```

### Source Install (apt / pacman, latest per package)

```bash
pacman -S opencode              # native mainline
pacman -S opencode-wrapper      # wrapper appendix (renamed from opencode-glibc)
pacman -S opencode-compressed   # UPX packed

apt update && apt install opencode-compressed   # or opencode / opencode-wrapper
```

> The apt flat index (`Packages.gz`) only contains the **latest version** of each package name.
> To install a specific older version, use manual install below, pulling directly from release assets.

### Manual Install (specific version)

```bash
pacman -U opencode-<ver>-1-aarch64.pkg.tar.xz             # native / wrapper
dpkg    -i opencode_<ver>_aarch64.deb
pacman -U opencode-compressed-<ver>-1-aarch64.pkg.tar.gz  # compressed (note .gz)
dpkg    -i opencode-compressed_<ver>_aarch64.deb
pacman -U opencode-wrapper-standalone-<ver>-1-aarch64.pkg.tar.xz  # standalone rollback
dpkg    -i opencode-wrapper-standalone_<ver>_aarch64.deb
```
