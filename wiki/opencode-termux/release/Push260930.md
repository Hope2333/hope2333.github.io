# Push260930 — RC5: B1 (native-gnu) finalized

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260930) · [中文](../../zh_CN/release/Push260930.md)

## Overview

**RC5 = B1 (native-gnu) finalized** per [RFC discussions/29](https://github.com/Hope2333/opencode-termux/discussions/29):
all 19 v2 native versions (2.0.0-2.0.18) rebuilt with the **upstream gnu PTY
asset kept as-is** (**PKGREL=5**), with the seccomp shim still shipped in every
package (#17/#24 fixes not regressed). First finalized family of the dual-line
plan — RC6 will finalize B2 (native-musl).

**38 assets** (v2 native 19 versions, deb + pacman), per-asset digest verified.

| Compare | B1 (this RC5) | B2 (shipped in RC4 / finalized in RC6) |
|---------|---------------|----------------------------------------|
| PTY helper | upstream gnu variant as-is (continuity) | fully static musl variant (#27 fix) |
| Runtime | stable in the vast majority of environments (incl. zero-glibc) | robust in all environments incl. fragile kernels |
| Purity | contains a glibc element | zero glibc contamination |

**Mutual exclusion**: B1 vs B2 pick-one within the generation; also
mutually exclusive with wrapper/compressed; cross-generation v1 coexists;
`*-standalone` is the coexistence exception.

## Install

```bash
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

pacman -S opencode    # v2 mainline (this release = B1 gnu finalized, PKGREL=5)
pacman -S opencode1   # v1 mainline (coexists with v2)
```

Manual (pinned): `pacman -U opencode-2.0.18-5-aarch64.pkg.tar.xz`
