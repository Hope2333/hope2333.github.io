# Project Docs Directory

> Direct pointers to the official documentation of hope2333 projects, listed in the docs' original language

Links always point to the **docs in their original language** (Chinese docs are linked in Chinese, English docs in English) and never through localized copies of this site. Every link was verified reachable (HTTP 200) at the time of inclusion; projects without usable documentation get no pointer and none are invented.
