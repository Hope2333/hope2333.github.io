# Push260906 — Formal Release

Three-family, dual-format package train. Supersedes Push260903.

## What's New

- 13 versions (1.18.15–1.18.27) × 3 families × 2 formats = 78 packages
- Native mainline: pure Bionic, zero glibc, seccomp SIGSYS shim, TUI, bin-direct
- Glibc appendix: bin-only packaging (single binary, no maintainer hooks), self-contained composite (no Termux glibc packages required)
- Compressed family: UPX-packed runtime, gzip fast-wrap packages, always ships `libopencode-crhandler.so`
- UPX runtime assets: `opencode-native-<ver>-upx.xz` (13)
- SHA256SUMS.txt with 91 verified entries
- Latest: v1.18.27
