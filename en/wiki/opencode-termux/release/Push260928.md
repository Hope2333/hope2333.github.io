# Push260928 — RC4 Fixes & Completion

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260928)

## Overview

RC4 = the RC3 two-generation family, **corrected and completed** — **84 planned
assets** (plus repo db/mirrorlist via site-rebuild self-heal):

- **seccomp shim shipped in every v2 native package** (fixes #17/#24:
  `Bad system call` on older kernels such as 4.19) — whole v2 native line
  rebuilt as **PKGREL=4** with `harden-native` wired into the chain
- **PTY helper switched to the upstream official musl fully-static variant**
  (fixes #27: glibc ABI cannot load under bionic) — per-build embedded-hash
  assertion after every build
- **Range completion**: v2.0.13–2.0.17 (B-line) and v1.18.33 (A-line) added
- **stale-serve-kill install hook** ships only in v2 2.0.[0-3] (packaging hook
  registry: `HOOKS_ENABLE` / `HOOKS_DISABLE` + version-range defaults; verified
  firing on 2.0.0, not firing on 2.0.5)

| Family | Generation | Package | Format | Notes |
|--------|-----------|---------|--------|-------|
| native (mainline) | v2 | `opencode` | deb + pacman `.pkg.tar.xz` | Zero-glibc bionic ELF; PKGREL=4, shim + musl pty embedded |
| native (mainline) | v1 | `opencode1` | deb + pacman `.pkg.tar.xz` | Zero-glibc bionic ELF, direct exec |
| wrapper (appendix) | v2 | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | bun-termux-loader wrap |
| wrapper (appendix) | v1 | `opencode1-wrapper` | deb + pacman `.pkg.tar.xz` | glibc runtime payload |
| compressed (UPX) | v1 | `opencode1-compressed` | deb + pacman `.pkg.tar.gz` | UPX 外包压制，见 opencode-compressed-branch |

**Mutual exclusion**: across generations `opencode1` (v1) and `opencode` (v2)
CAN coexist side by side; within the same generation install exactly ONE of
native / wrapper / compressed.

Version coverage: v2 native 19 versions (2.0.0–2.0.18) / v2 wrapper 13
(2.0.0–2.0.12) / v1 native 4 (1.18.30–33) / v1 wrapper & compressed 3 each
(1.18.30–32).

## Install

### Configure the software source (once)

```bash
# One-liner: configure sources and install (pacman + apt in one go)
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode
```

### Install from the software source (apt / pacman)

```bash
# v2 mainline
pacman -S opencode            # or opencode-wrapper
apt update && apt install opencode
# v1 mainline (coexists with v2)
pacman -S opencode1           # or opencode1-wrapper / opencode1-compressed
apt update && apt install opencode1
```

### Manual install (pinned version)

```bash
pacman -U opencode-2.0.18-4-aarch64.pkg.tar.xz              # v2 native (PKGREL=4, shim included)
pacman -U opencode1-1.18.33-3-aarch64.pkg.tar.xz            # v1 native (PKGREL=3)
pacman -U opencode1-compressed-1.18.32-3-aarch64.pkg.tar.gz # v1 compressed (note .gz)
dpkg -i opencode_2.0.18_aarch64.deb
dpkg -i opencode1_1.18.33_aarch64.deb
```

> deb has no pkgrel concept (--clobber overwrite); v2 native pac names carry
> `-4-`, all other families `-3-`.
