# Push260903 — Formal Release

First formal release of the dual-family, dual-format package train.

## What's New

- 13 versions (1.18.15–1.18.27) × 2 families × 2 formats = 52 packages
- Native mainline: pure Bionic, zero glibc, seccomp SIGSYS shim, TUI, bin-direct
- Glibc appendix: renamed from `opencode` → `opencode-glibc`
- SHA256SUMS.txt with 52 verified entries
