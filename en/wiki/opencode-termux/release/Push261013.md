# Push261013 — all-families batch: v2 2.0.23–2.0.27 + v1 1.18.35 / 1.19.0

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261013) · [中文版](/zh_CN/wiki/opencode-termux/release/Push261013.md)

## Overview

**Push261013** ships upstream **v2 2.0.23–2.0.27** (5 versions) and **v1
1.18.35 / 1.19.0** (2 versions, including the new 1.19.0 minor line), each in
**all three families**: native, UPX-compressed, and wrapper (**deb only**, per
convention). All first releases → rel is uniformly **1**.

**36 assets**: 35 packages + `SHA256SUMS.txt` (35 entries)

| Family | Versions | Formats | Count |
|--------|----------|---------|-------|
| `opencode` (v2 native) | 2.0.23 – 2.0.27 | deb + `.pkg.tar.xz` | 5 + 5 |
| `opencode1` (v1 native) | 1.18.35, 1.19.0 | deb + `.pkg.tar.xz` | 2 + 2 |
| `opencode-compressed` | 2.0.23 – 2.0.27 | deb + `.pkg.tar.gz` | 5 + 5 |
| `opencode1-compressed` | 1.18.35, 1.19.0 | deb + `.pkg.tar.gz` | 2 + 2 |
| `opencode-wrapper` | 2.0.23 – 2.0.27 | deb only | 5 |
| `opencode1-wrapper` | 1.18.35, 1.19.0 | deb only | 2 |

**Build provenance**: v2 native compiled from source (android bun, B-line
`build-bionic.sh`) with **per-version dependency pins** — opentui **0.5.14**
(2.0.23/24), **0.5.16** (2.0.25), **0.5.17** (2.0.26/27), pty **0.2.0** across
the board; v1 native via the transplant revive pipeline (bun 1.4.0 base;
`transplant.py predict` passed 7/7). Compression by the in-repo
`tools/compressed-one.sh` (UPX -4, ratio ≈ 31–38%). Every package passed three
smoke gates before upload (`--version` version gate + isolated `--dbpath
--help` + TUI probe); every upload verified for state/size/sha256-digest.

**Mutual exclusion**: within a generation, native / wrapper / compressed are
mutually exclusive; across generations, v1 (`opencode1*`) and v2 (`opencode*`)
can coexist; `*-standalone` is the coexistence exception.

## Install

```bash
# pacman (rel=1 this batch)
pacman -U ./opencode-2.0.27-1-aarch64.pkg.tar.xz
# deb
dpkg -i ./opencode_2.0.27_aarch64.deb
```
