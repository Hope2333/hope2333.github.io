# exagear-obb

> ExaGear OBB builder scripts

## Overview

ExaGear OBB builder scripts. This project provides a set of scripts for building ExaGear OBB files, simplifying the packaging of ExaGear-related assets.

## Installation

This project is not yet in the hope2333 repository. Please get it from the [GitHub repository](https://github.com/Hope2333/exagear-obb); see the repository README for installation instructions.
