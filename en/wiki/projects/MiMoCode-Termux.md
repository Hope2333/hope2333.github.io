# MiMoCode-Termux

> MiMoCode for Termux, based on opencode-termux

## Overview

MiMoCode for Termux, built on top of opencode-termux. This project brings MiMoCode to the Termux platform, reusing the work done in opencode-termux.

## Installation

This project is not yet in the hope2333 repository. Please get it from the [GitHub repository](https://github.com/Hope2333/MiMoCode-Termux); see the repository README for installation instructions.
