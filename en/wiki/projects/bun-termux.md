# bun-termux

> Bun runtime for Termux

## Overview

Bun runtime for Termux. This project provides the Bun runtime for the Termux platform, making it easy to run Bun and its ecosystem tools on Android devices.

## Installation

This project is not yet in the hope2333 repository. Please get it from the [GitHub repository](https://github.com/Hope2333/bun-termux); see the repository README for installation instructions.
