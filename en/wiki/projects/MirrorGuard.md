# MirrorGuard

> C-based file integrity checker with TUI

## Overview

A file integrity checker written in C with a TUI. This project is a file integrity verification tool implemented in C, bundled with a TUI for interactively inspecting verification results.

## Installation

This project is not yet in the hope2333 repository. Please get it from the [GitHub repository](https://github.com/Hope2333/MirrorGuard); see the repository README for installation instructions.
