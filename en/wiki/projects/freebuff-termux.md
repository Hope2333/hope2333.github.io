# freebuff-termux

> Freebuff AI coding assistant for Termux

## Overview

Freebuff AI coding assistant for Termux. This project brings Freebuff, an AI coding assistant, to the Termux platform so it can be used on Android devices.

## Installation

This project is not yet in the hope2333 repository. Please get it from the [GitHub repository](https://github.com/Hope2333/freebuff-termux); see the repository README for installation instructions.
