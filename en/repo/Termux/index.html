Termux Manual Setup · Hope2333

Try the one-click script first: /en/repo/ install.sh (auto-detects Termux, configures the unified repo, installs the hope2333-mirrorlist package, migrates old config automatically, idempotent). Manual setup instructions follow.

Pacman repo configuration (unified repo + mirrorlist package)

  1. Append the unified section to the end of $PREFIX/etc/pacman.conf:
[hope2333]
Server = https://github.com/Hope2333/codegraph-termux/releases/latest/download/
Server = https://github.com/Hope2333/opencode-termux/releases/latest/download/
Server = https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/
Server = https://github.com/Hope2333/freebuff-termux/releases/latest/download/
Server = https://github.com/Hope2333/codebuff-termux/releases/latest/download/
Server = https://hope2333.github.io/repo/Termux/pacman/
SigLevel = Optional TrustAll
  1. Install the mirrorlist package: pacman -Sy && pacman -S hope2333-mirrorlist (after installation, the package hook replaces the manual section with a single Include = /etc/pacman.d/hope2333-mirrorlist.conf line — the managed conf carries its own section header and Server/SigLevel lines; keeping a same-named section in pacman.conf would double-register it and lose the Servers. Repo changes then take effect through package upgrades)

If you still have the legacy [hope2333-meta] bootstrap section or an old [hope2333] block (single or multiple Server lines): replace it entirely with this unified section — do not append. Duplicate registration fails with database already registered; alternatively, just re-run install.sh to migrate automatically.

APT repo configuration (bootstrap repo + mirrorlist package)

  1. Write the bootstrap line to $PREFIX/etc/apt/sources.list.d/hope2333-bootstrap.list:
deb [trusted=yes arch=aarch64] https://hope2333.github.io/repo/Termux/apt/ ./
  1. Install the mirrorlist package: apt update && apt install hope2333-mirrorlist (the package writes hope2333.list — 5 flat lines pointing at each repo's Release latest)

The old deb .../repo/Termux/apt/ stable main line is obsolete (the apt repo is no longer hosted on io); remove it or replace it with the bootstrap line.

Manual configuration (without installing the hope2333-mirrorlist package) 
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/codegraph-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/opencode-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/freebuff-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/codebuff-termux/releases/latest/download/ ./

The unified repo section matches the contents of the hope2333-mirrorlist package; MiMoCode is a pre-release channel pinned explicitly to Push260829 (GitHub does not allow a prerelease to be Latest, so releases/latest would 404).

Signature verification (repo-add -s / Release signatures) will be introduced later; v1 is currently unsigned.
