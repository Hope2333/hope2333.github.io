Pacman Repository (Termux)

Install the Termux packages published on this site via the unified [hope2333] repo + hope2333-mirrorlist package.

Recommended flow (unified repo + mirrorlist package)

  1. Append the unified section to the end of $PREFIX/etc/pacman.conf:
[hope2333]
Server = https://github.com/Hope2333/codegraph-termux/releases/latest/download/
Server = https://github.com/Hope2333/opencode-termux/releases/latest/download/
Server = https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/
Server = https://github.com/Hope2333/freebuff-termux/releases/latest/download/
Server = https://github.com/Hope2333/codebuff-termux/releases/latest/download/
Server = https://hope2333.github.io/repo/Termux/pacman/
SigLevel = Optional TrustAll
  1. Install the mirrorlist package: pacman -Sy && pacman -S hope2333-mirrorlist;
  2. After installation, the package hook replaces the manual section with a single Include = /etc/pacman.d/hope2333-mirrorlist.conf line (the managed conf carries its own section header and Server/SigLevel lines; keeping a same-named section in pacman.conf would double-register it and lose the Servers). Repo changes then take effect through package upgrades.

Once configured, you can install packages, e.g. pacman -S codegraph.

If you still have the legacy [hope2333-meta] bootstrap section or an old [hope2333] block (single or multiple Server lines): replace it entirely with this unified section — do not append. Duplicate registration fails with database already registered; alternatively, just re-run install.sh to migrate automatically.

The unified db (hope2333.db.tar.gz) covers packages from all five repos plus hope2333-mirrorlist, hosted on this site and on each Release CDN; package files fall back file-by-file through the Server list in order and are ultimately downloaded from the GitHub Release CDN (302 follows handled automatically). MiMoCode is a pre-release channel pinned explicitly to Push260829. The v1 repo is unsigned, hence Optional TrustAll; a repo-add -s upgrade is planned.
