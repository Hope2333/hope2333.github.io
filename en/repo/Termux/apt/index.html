APT Repository (Termux)

Install the Termux packages published on this site via the bootstrap repo + hope2333-mirrorlist package.

Recommended flow (bootstrap repo + mirrorlist package)

  1. Write the bootstrap line to $PREFIX/etc/apt/sources.list.d/hope2333-bootstrap.list:
deb [trusted=yes arch=aarch64] https://hope2333.github.io/repo/Termux/apt/ ./
  1. Install the mirrorlist package: apt update && apt install hope2333-mirrorlist;
  2. The package writes hope2333.list (5 flat lines pointing at each repo's Release latest); repo changes then take effect through package upgrades.

Once configured, you can install packages, e.g. apt install codegraph.

The old deb .../repo/Termux/apt/ stable main line is obsolete (the apt repo is no longer hosted on io); remove it or replace it with the bootstrap line.

Manual configuration (fallback)

Expand the 5-line flat repos (without installing hope2333-mirrorlist) 
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/codegraph-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/opencode-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/freebuff-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/codebuff-termux/releases/latest/download/ ./

This only works if each source repo's release provides Packages.gz (termux-asset-update v7.2); until then the flat lines return 404. This site (io) no longer hosts any package files. MiMoCode is a pre-release channel pinned explicitly to Push260829.
