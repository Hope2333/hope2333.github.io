# Push260930 — RC5：B1（native-gnu）定版

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260930) · [English](/wiki/opencode-termux/release/Push260930.md)

## 概览

**RC5 = B1（native-gnu）定版**（[RFC discussions/29](https://github.com/Hope2333/opencode-termux/discussions/29) 裁决）：v2 native 全 19 版（2.0.0-2.0.18）以 **gnu PTY 资产延续**重建上架（**PKGREL=5**），seccomp shim 照常随包（#17/#24 修复不回退）。双线并行第一支定版——RC6 将以 B2（native-musl）收口。

**38 件**（v2 native 19 版 deb + pacman），逐件 digest 对账。

| 对比 | B1（本版 RC5） | B2（RC4 已上架 / RC6 定版） |
|------|---------------|------------------------------|
| PTY 助手 | 上游 gnu 变体原样（延续现状） | musl 全静态变体（#27 修复） |
| 运行面 | 绝大多数环境稳定（含零 glibc） | 全环境含脆弱内核 |
| 纯度 | 含 glibc 元素 | 零 glibc 沾染 |

**同代互斥**：B1 与 B2 二选一；与 wrapper/compressed 同代互斥；跨代 v1 可共存；`*-standalone` 为共存例外。

## Install

```bash
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

pacman -S opencode    # v2 mainline（本版 = B1 gnu 定版，PKGREL=5）
pacman -S opencode1   # v1 mainline（跨代共存）
```

手动（钉版本）：`pacman -U opencode-2.0.18-5-aarch64.pkg.tar.xz`
