# Push261013 — 全家族批次：v2 2.0.23–2.0.27 + v1 1.18.35 / 1.19.0

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261013) · [English](/wiki/opencode-termux/release/Push261013.md)

## 概览

**Push261013** 一次带上游 **v2 五版（2.0.23–2.0.27）** 与 **v1 两版（1.18.35、1.19.0 新 minor 线）**，每版三族齐发：native、UPX 压制 compressed、wrapper（**仅 deb**，沿用惯例）。全部为首次发布，rel 一律 **=1**。

**36 件**：35 包 + `SHA256SUMS.txt`（35 条）

| 家族 | 版本范围 | 格式 | 数量 |
|------|----------|------|------|
| `opencode`（v2 native） | 2.0.23 – 2.0.27 | deb + `.pkg.tar.xz` | 5 + 5 |
| `opencode1`（v1 native） | 1.18.35、1.19.0 | deb + `.pkg.tar.xz` | 2 + 2 |
| `opencode-compressed` | 2.0.23 – 2.0.27 | deb + `.pkg.tar.gz` | 5 + 5 |
| `opencode1-compressed` | 1.18.35、1.19.0 | deb + `.pkg.tar.gz` | 2 + 2 |
| `opencode-wrapper` | 2.0.23 – 2.0.27 | 仅 deb | 5 |
| `opencode1-wrapper` | 1.18.35、1.19.0 | 仅 deb | 2 |

**构建谱系**：v2 native 走 B 线源码编译（android bun），依赖钉版按上游逐版对齐——opentui **0.5.14**（2.0.23/24）、**0.5.16**（2.0.25）、**0.5.17**（2.0.26/27），pty 统一 **0.2.0**；v1 native 走 transplant 复活线（bun 1.4.0 底座，`transplant.py predict` 七版全 OK）。压制由入库工具 `tools/compressed-one.sh` 完成（UPX -4，压缩率 ≈ 31–38%）。每包上传前过三道冒烟（`--version` 版本门 + `--dbpath --help` 隔离 + TUI probe），上传后逐件核验 state/size/sha256-digest。

**同代互斥**：同代内 native / wrapper / compressed 三选一；跨代 v1（`opencode1*`）与 v2（`opencode*`）可共存；`*-standalone` 为共存例外。

## 安装

```bash
# pacman（本批 rel=1）
pacman -U ./opencode-2.0.27-1-aarch64.pkg.tar.xz
# deb
dpkg -i ./opencode_2.0.27_aarch64.deb
```

## 校验

- 版本连续性：v2 2.0.0–2.0.27、v1 1.18.8–1.18.35 + 1.19.0 全库存可追（Push260803 → 本 tag）
- `SHA256SUMS.txt` 覆盖全部 35 包：`sha256sum -c SHA256SUMS.txt`
- 双代矩阵：`opencode`（v2）与 `opencode1`（v1）可同装，数据由分代 launcher 隔离
