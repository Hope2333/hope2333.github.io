# Push260912 — opencode-wrapper 正式リリース

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260912)

## 概要

ローリング Push タグサイクルにより、**`opencode-glibc` → `opencode-wrapper` の改称**が完了し、4 ファミリーマトリクスが揃いました。バージョンは **v1.18.30**。

| ファミリー | パッケージ名 | 形式 | 概要 |
|--------|-------------|--------|-------------|
| native（メインライン） | `opencode` | deb + pacman `.pkg.tar.xz` | ゼロ glibc bionic ELF、そのまま実行可能 |
| wrapper（付録） | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | glibc ラッパー — `opencode-glibc` から改称 |
| compressed（圧縮） | `opencode-compressed` | deb + pacman `.pkg.tar.gz` | UPX --best 圧縮 |
| standalone（ロールバック用） | `opencode-wrapper-standalone` | deb + pacman `.pkg.tar.xz` | 凍結済み単一バージョンのロールバック用、`opencode` と共存 |

`SHA256SUMS.txt`（完全検証用）と `Packages.gz`（apt flat ソースインデックス）も同梱されます。

## パッケージ改称：opencode-glibc → opencode-wrapper

glibc 付録ファミリーは `opencode-wrapper` に改称されました：

- **deb**: `Replaces: opencode-glibc` + `Breaks: opencode-glibc (<< version)` — 既存の `opencode-glibc` ユーザーは `opencode-wrapper` へ**自動アップグレード**され、手動操作は不要です。
- **pacman**: `replaces=('opencode-glibc')` — 同じ自動アップグレードのセマンティクスです。

**相互排他**：`opencode` ↔ `opencode-wrapper` は相互排他で、`opencode-compressed` は `opencode` を Provides するため、3 つのうちいずれか 1 つのみインストールできます。`opencode-wrapper-standalone` は `opencode-wrapper` と相互排他ですが、`opencode` とは共存できます（ロールバック専用経路）。

## インストール

### ソース設定（1 回だけ）

```bash
# ワンショット：ソース設定とインストール（pacman + apt ソースが揃います）
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

# または手動：
# pacman — 統一 [hope2333] セクションを $PREFIX/etc/pacman.conf に追記（完全なブロックは
#   /repo/Termux/ の手動設定ブロック参照）し、pacman -Sy && pacman -S hope2333-mirrorlist
#   （インストール後フックがセクションをセクションヘッダ + Include 形式へ収束）
# apt — $PREFIX/etc/apt/sources.list.d/hope2333.list に書き込み：
#   deb [trusted=yes arch=aarch64] https://github.com/Hope2333/opencode-termux/releases/latest/download/ ./
```

### ソースからインストール（apt / pacman、各パッケージの最新版）

```bash
pacman -S opencode              # native メインライン
pacman -S opencode-wrapper      # wrapper 付録（opencode-glibc から改称）
pacman -S opencode-compressed   # UPX 圧縮

apt update && apt install opencode-compressed   # または opencode / opencode-wrapper
```

> apt flat インデックス（`Packages.gz`）には各パッケージ名の**最新バージョン**のみ含まれます。
> 特定の旧バージョンをインストールする場合は、後述の手動インストールで release アセットから直接取得してください。

### 手動インストール（バージョン指定）

```bash
pacman -U opencode-<ver>-1-aarch64.pkg.tar.xz             # native / wrapper
dpkg    -i opencode_<ver>_aarch64.deb
pacman -U opencode-compressed-<ver>-1-aarch64.pkg.tar.gz  # compressed（.gz に注意）
dpkg    -i opencode-compressed_<ver>_aarch64.deb
pacman -U opencode-wrapper-standalone-<ver>-1-aarch64.pkg.tar.xz  # standalone ロールバック
dpkg    -i opencode-wrapper-standalone_<ver>_aarch64.deb
```
