# Push260922 — RC3 両世代フルファミリーリフレッシュ

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260922)

## 概要

RC3 はスクラッチからの再ビルドです。Push260922 の当初 69 アセットを一度全消去し、**PKGREL=3**（第 3 リリースマーカー）で両世代フルファミリーを再ビルド・再アップロードしました — 合計**計画 70 アセット**（site-rebuild による repo db／mirrorlist の自己修復分を除く）。クラッシュしやすかった旧 bun-1.4.2 時代のビルドと陳腐化したパッケージは一掃され、すべてリポジトリの最新 HEAD からビルドされています。

| ファミリー | 世代 | パッケージ | 形式 | 備考 |
|--------|-----------|---------|--------|-------|
| native（メインライン） | v2 | `opencode` | deb + pacman `.pkg.tar.xz` | ゼロ glibc bionic ELF、直接実行 |
| native（メインライン） | v1 | `opencode1` | deb + pacman `.pkg.tar.xz` | ゼロ glibc bionic ELF、直接実行 |
| wrapper（付録） | v2 | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | bun-termux-loader wrap |
| wrapper（付録） | v1 | `opencode1-wrapper` | deb + pacman `.pkg.tar.xz` | glibc ランタイム payload |
| compressed（UPX） | v1 | `opencode1-compressed` | deb + pacman `.pkg.tar.gz` | UPX は外部委託（opencode-compressed-branch 参照） |

**相互排他**：世代をまたいで `opencode1`（v1）と `opencode`（v2）は**共存可能**です。同一世代内では native / wrapper / compressed のうち**必ず 1 つだけ**インストールしてください。

バージョン範囲：v2 native & wrapper 各 13 バージョン（2.0.0–2.0.12）+ v1 3 ファミリー × 3 バージョン（1.18.30–32）。

## インストール

### ソフトウェアソースの設定（1 回だけ）

```bash
# ワンライナー：ソース設定とインストール（pacman + apt を一気に）
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode
```

### ソースからインストール（apt / pacman、両世代共存）

```bash
# v2 メインライン
pacman -S opencode            # または opencode-wrapper
apt update && apt install opencode
# v1 メインライン（v2 と共存）
pacman -S opencode1           # または opencode1-wrapper / opencode1-compressed
apt update && apt install opencode1
```

### 手動インストール（バージョン指定）

```bash
pacman -U opencode-2.0.12-3-aarch64.pkg.tar.xz              # v2 native（PKGREL=3）
pacman -U opencode1-1.18.32-3-aarch64.pkg.tar.xz            # v1 native（PKGREL=3）
pacman -U opencode1-compressed-1.18.32-3-aarch64.pkg.tar.gz # v1 compressed（.gz に注意）
dpkg -i opencode_2.0.12_aarch64.deb
dpkg -i opencode1_1.18.32_aarch64.deb
```

> deb には pkgrel の概念がありません — バージョンは同一のまま（--clobber で上書き）。pacman 製品はファイル名に `-3-` が入ります。
