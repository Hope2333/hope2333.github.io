# Push261016 — seccomp hardening fix (#36) + v2 2.0.28–2.0.31 + v1 1.19.1–1.19.3

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261016) · [中文版](/zh_CN/wiki/opencode-termux/release/Push261016.md) · [English](/en/wiki/opencode-termux/release/Push261016.md) · [Español](/es/wiki/opencode-termux/release/Push261016.md) · [日本語](/ja/wiki/opencode-termux/release/Push261016.md) · [繁體中文](/zh_TW/wiki/opencode-termux/release/Push261016.md)

## Summary

Two things in this batch: ①**Issue #36 fix (seccomp hardening)** — native
packages now interpose `libopencode-crhandler.so` (DT_NEEDED[0]), so
`close_range` no longer SIGSYSkills on Android 12; affected versions were
repacked. ②**New versions**: v2 2.0.28–2.0.31 (4) + v1 1.19.1–1.19.3 (3), all
three families (wrapper deb-only). **84 assets** (83 packages + SHA256SUMS.txt),
rel=1 across the board. Same-generation mutual exclusion; cross-generation
`opencode1*`×`opencode*` coexist; v1 packages `< 2.0.0`, v2 `>= 2.0.0`.

## 既知の問題

- **古いカーネル（< 4.x、Android 9 の 3.18.x など）**: opencode **1.18.35 以降**（v1、1.19.x 系を含む）および**すべての v2 バージョン**では、起動直後のインタラクティブ TUI が **SIGSEGV**（rc 139）でクラッシュし、これらのカーネルでは TUI を使用できません。**CLI モードは影響を受けません。**
- **回避策**: 古いカーネルでは、**1.18.34 以前**のままにする（3.18.140 で TUI の安定動作を実証済み）か、**1.19.3 native ハイブリッドパッケージ**（新しい CLI + 1.18.34 の OpenTUI レンダラー）を使用します。**`--force-tui`** を付けると TUI が復活し、付けない場合はランチャーが古いカーネルを検出して**自動的に CLI モードにフォールバック**し、2 言語（zh/en）の通知を出します。ハイブリッドパッケージは native の deb/pacman のみで提供し、compressed（UPX）版は**公開しません**（UPX×graft の組み合わせは動作不能になることが実証済みのため）。

Install: `pacman -U ./opencode-2.0.31-1-aarch64.pkg.tar.xz` or
`dpkg -i ./opencode_2.0.31_aarch64.deb`; verify:
`sha256sum -c SHA256SUMS.txt`.
