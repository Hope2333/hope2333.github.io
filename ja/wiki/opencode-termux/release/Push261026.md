# Push261026 — v2 2.1.4（OpenTUI 0.6.8 ABI 修正）+ v2 2.0.32

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261026) · [中文版](/zh_CN/wiki/opencode-termux/release/Push261026.md) · [English](/en/wiki/opencode-termux/release/Push261026.md) · [Español](/es/wiki/opencode-termux/release/Push261026.md) · [日本語](/ja/wiki/opencode-termux/release/Push261026.md) · [繁體中文](/zh_TW/wiki/opencode-termux/release/Push261026.md)

## 概要

native ファミリー、v2 の 2 バージョン、各 deb + pacman `.pkg.tar.xz` の
**4 パッケージ + SHA256SUMS.txt**。**2.0.32** は 2.0 系の最終版（opentui
0.5.17）、**2.1.4** は 0.6.x レンダラ ABI に載った最初の 2.1 系（opentui
0.6.8）。ABI の異なる 2 系統であり、必要に応じて選んでください。`opencode`
というパッケージ名を共有するため、一方を入れるともう一方は置き換わります。

**重要な修正（commit `d7ddcb5`）**: 2.1.4 の最初のビルドは 0.6.8 の JS に
0.5.x 世代の bionic `libopentui.so` を組み合わせており、TUI が
`Symbol "ot_scene_set_hooks" not found` で起動直後に終了していました（CLI と
`serve` は正常）。ライブラリを上流 `sst/OpenTUI v0.6.8` から再ビルドし
（上流 glibc 版とエクスポート面を比較して 1829 個中 0 欠落、`libc.so.6`
依存なし）、ビルドは `OPENTUI_VER` で選択するようになりました。未知の
バージョンは誤った ABI にフォールバックせず失敗します。

## 検証

実機（Android 9 / kernel `3.18.140-mokee` / aarch64）: 両バージョンとも
`--version` 正常、`serve` は HTTP 200、TUI は完全描画（2.0.32 は 123,184 B、
2.1.4 は 101,980 B、バナー・入力欄・セッション一覧を確認）、15 秒以上生存。
`make verify-artifact` PASS（seccomp 強化 + web UI アセット）、shell テスト
76 ok。

## 既知の問題

- 本批は **native** のみ。compressed（UPX）と wrapper は含みません。**v1 は
  1.19.3 のまま**です。上流 1.19.4 は依然 `effect 4.0.0-beta.83` を固定して
  おり、3.18 カーネルで SIGSEGV するため、ソース再ビルドが必要です。
- 旧 v1（1.18.35 以降）と以前の v2 の古いカーネルでの TUI 問題は継続します。
  [Push261016](/ja/wiki/opencode-termux/release/Push261016.md) を参照。**2.0.32 と 2.1.4 は 3.18.140
  で動作確認済みです。**
- `opencode1` と v2 の共存インストールでは、seccomp shim の共有パスのため
  引き続き `dpkg --force-overwrite` が必要です。後の批次で解消します。

インストール: `pacman -U ./opencode-2.1.4-1-aarch64.pkg.tar.xz` または
`dpkg -i ./opencode_2.1.4_aarch64.deb`、検証:
`sha256sum -c SHA256SUMS.txt`。
