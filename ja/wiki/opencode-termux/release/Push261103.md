# Push261103 — v2 2.0.32 → 2.2.5 / v1 1.18.33 → 1.19.4

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261103) · [中文版](/zh_CN/wiki/opencode-termux/release/Push261103.md) · [English](/en/wiki/opencode-termux/release/Push261103.md) · [Español](/es/wiki/opencode-termux/release/Push261103.md) · [日本語](/ja/wiki/opencode-termux/release/Push261103.md) · [繁體中文](/zh_TW/wiki/opencode-termux/release/Push261103.md)

## 概要

今回のバッチは不足分をまとめて解消します。最新版だけでなく、両世代の
**検証済みバージョンをすべて**公開します。

- **v2 native** — `2.0.32`、`2.1.0`–`2.1.4`、`2.2.0`–`2.2.5`（12 バージョン）
- **v1 native** — `1.18.33`–`1.18.35`、`1.19.0`–`1.19.4`（8 バージョン）

各バージョンは **deb** と **pacman**（`.pkg.tar.xz`）の 2 形式：
**40 パッケージ + SHA256SUMS.txt**。すべて glibc 非依存の Android ネイティブ
バイナリで、上流ソースを android-bun でビルドし、TUI はソースから再ビルドした
bionic 版 `libopentui.so` で描画します（wrapper なし、proot なし、musl 非依存）。

## レンダラ系列（「新しいほど良い」ではなく系列で選ぶ）

| v2 系列 | opentui | 備考 |
|---|---|---|
| `2.0.32` | 0.5.17 | 2.0 系列の最終版 |
| `2.1.0`–`2.1.4` | 0.6.6 → 0.6.8 | `ot_*` コンテキスト ABI 最初の系列 |
| `2.2.0`–`2.2.2` | 0.7.0 | FFI 面が更新。`2.2.2` で上流が `@opencode-ai/pty` を削除 |
| `2.2.3`–`2.2.5` | 0.8.0 | pty が `@opencode/pty` として復帰（0.3.3、2.2.4 から 0.4.0） |

`opencode`（v2）と `opencode1`（v1）は共存可能でランタイムパスを共有しません。
v2 内部では同名パッケージの別バージョンが上書きされるため、系列を 1 つ選んでください。

## 今回のビルド修正

- **vite 8 のネイティブバインディング**：`bun install --os=linux` がツリー全体を
  再解決し、android 専用の optional 依存（`rolldown`、`lightningcss`、
  `@tailwindcss/oxide`）を削除してしまい、web UI ビルドが
  `Cannot find native binding` で失敗していました。`bun.lock` の
  `{os:android,cpu:arm64}` エントリから tarball を直接取得して復元します。
- **プラットフォームパッケージ**：パッケージごとに完全な `bun install` を回すのを
  やめ、レジストリから直接取得します（以前は 1 回ごとに 10 分のタイムアウト）。
- **PTY パッケージ名の変更**：上流が `@opencode-ai/pty` を `@opencode/pty` に改名
  （2.2.2 で削除、2.2.3 で復帰）。パッケージ名はバージョン行列から解決します。
- **opentui 0.8.0 のパッチアンカー**：ネイティブアセットのターゲットが
  `getCurrentNodeAssetTarget()` に移り、上流で `platform: "linux"` が固定されました。
  パッチ手順は旧アンカーで失敗せず、この性質を検証する形に変更しました。

## 検証

本バッチの全バージョンが参照機（Android 9 / kernel `3.18.140-mokee` / aarch64）で
同一の判定基準を通過しています：

`インストール → --version → serve HTTP 200 → TUI フレーム → キー入力エコー →
15 秒生存 → クラッシュ/劣化マーカーなし`

`2.2.0`–`2.2.5` は 2026-11-03 に本バッチ向けに再検証し、残りは各ビルド回で
同一機にて検証済みです。各パッケージは `make verify-artifact` も通過し
（seccomp shim、v2 は web UI 同梱）、アップロード後の digest は
`SHA256SUMS.txt` と 1 件ずつ一致しています。

## 既知の問題

- **v2 と `opencode1` の共存インストール**では、共有 seccomp shim のパスのため
  `dpkg --force-overwrite` が必要な場合があります。
- `2.2.5` の初回起動で `8 plugins failed` が表示されます。プラグイン互換性の警告で
  ありクラッシュではありません（TUI、`serve`、キー入力は影響なし）。
- 本バッチは **native** 系列のみです。compressed（UPX）と wrapper は含みません。

インストール：`pacman -U ./opencode-2.2.5-1-aarch64.pkg.tar.xz` または
`dpkg -i ./opencode_2.2.5_aarch64.deb`。検証：`sha256sum -c SHA256SUMS.txt`。
