# Push261005 — rc1：フリート B ライン再ビルド（rel 再パック、raw）

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261005) · [中文](/zh_CN/wiki/opencode-termux/release/Push261005.md)

## 概要

**Push261005** は、native ファミリーをフリート B ライン（**NDK r27c、strip なし**）で丸ごと**再ビルドした世代**です。rel は **prev-max+1 / 新バージョン=1** ルールで再パックしました（当初の `-90` アップロードは置き換え済み）。この世代は、旧 transplant 世代のパッケージとは**別のソース**です — 上流バージョンは同じでも、ツールチェーンの系譜が新しくなっています。native の deb もすべてこの世代から再パックされました。

**57 アセット**：pacman 28 + deb 28 + `SHA256SUMS.txt`

| ファミリー | バージョン | rel | 数（pacman + deb） |
|--------|----------|-----|----------------------|
| `opencode`（v2 native） | 2.0.0–2.0.10、2.0.12、2.0.15–2.0.18 | 6 | 16 + 16 |
| `opencode`（v2 native） | 2.0.11、2.0.13、2.0.14 | 5 | 3 + 3 |
| `opencode`（v2 native） | 2.0.19 – 2.0.22（新規） | 1 | 4 + 4 |
| `opencode1`（v1 native） | 1.18.30 – 1.18.33 | 4 | 4 + 4 |
| `opencode1`（v1 native） | 1.18.34（新規） | 1 | 1 + 1 |

**このバッチは raw（非圧縮）パッケージのみ**です — UPX 圧縮は外部委託です。**compressed ファミリーは後日生成され、同じタグへアップロードされます**（1 つのローリングバッチ、1 つのタグ）。wrapper / glibc / compressed ファミリーはこのバッチには**含まれません**。

**相互排他**：同一世代内では native / wrapper / compressed のうち**必ず 1 つだけ**選択。v1（`opencode1*`）と v2（`opencode*`）は共存可能。`*-standalone` は共存の例外です。

## インストール

```bash
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

pacman -S opencode     # v2 メインライン（本バッチ = rel 再パック、raw）
pacman -S opencode1    # v1 メインライン（v2 と共存）
```

手動（バージョン指定）：`pacman -U opencode-2.0.18-6-aarch64.pkg.tar.xz`
