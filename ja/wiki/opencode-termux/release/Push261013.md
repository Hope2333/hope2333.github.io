# Push261013 — 全ファミリーバッチ: v2 2.0.23–2.0.27 + v1 1.18.35 / 1.19.0

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261013) · [中文版](/zh_CN/wiki/opencode-termux/release/Push261013.md) · [English](/en/wiki/opencode-termux/release/Push261013.md) · [Español](/es/wiki/opencode-termux/release/Push261013.md) · [日本語](/ja/wiki/opencode-termux/release/Push261013.md) · [繁體中文](/zh_TW/wiki/opencode-termux/release/Push261013.md)

## 概要

**Push261013** は上流 **v2 2.0.23–2.0.27**（5 バージョン）と **v1 1.18.35 /
1.19.0**（2 バージョン、新しい 1.19.0 マイナーライン含む）を、**全 3
ファミリー**（native・UPX 圧縮・wrapper（**deb のみ**、慣例通り））でリリースします。すべて初リリースのため rel は一律 **1**。

**36 アセット**: 35 パッケージ + `SHA256SUMS.txt`（35 エントリ）

| ファミリー | バージョン | 形式 | 数 |
|-----------|-----------|------|-----|
| `opencode`（v2 native） | 2.0.23 – 2.0.27 | deb + `.pkg.tar.xz` | 5 + 5 |
| `opencode1`（v1 native） | 1.18.35, 1.19.0 | deb + `.pkg.tar.xz` | 2 + 2 |
| `opencode-compressed` | 2.0.23 – 2.0.27 | deb + `.pkg.tar.gz` | 5 + 5 |
| `opencode1-compressed` | 1.18.35, 1.19.0 | deb + `.pkg.tar.gz` | 2 + 2 |
| `opencode-wrapper` | 2.0.23 – 2.0.27 | deb のみ | 5 |
| `opencode1-wrapper` | 1.18.35, 1.19.0 | deb のみ | 2 |

**ビルド系統**: v2 native はソースからコンパイル（android bun、B 系
`build-bionic.sh`）、依存は上流バージョンごとにピン留め — opentui
**0.5.14**（2.0.23/24）・**0.5.16**（2.0.25）・**0.5.17**（2.0.26/27）、pty は全体 **0.2.0**。v1 native は transplant 復活パイプライン（bun 1.4.0 ベース、`transplant.py predict` 7/7 合格）。圧縮はリポジトリ内の `tools/compressed-one.sh`（UPX -4、圧縮率 ≈ 31–38%）。全パッケージがアップロード前に 3 つのスモークゲート（`--version` 版本ゲート + 隔離 `--dbpath --help` + TUI probe）を通過し、アップロード後は state/size/sha256-digest を検証済み。

**相互排他**: 同一世代内では native / wrapper / compressed は排他。世代を跨いで v1（`opencode1*`）と v2（`opencode*`）は共存可能。`*-standalone` は共存の例外。

## インストール

```bash
pacman -U ./opencode-2.0.27-1-aarch64.pkg.tar.xz
dpkg -i ./opencode_2.0.27_aarch64.deb
```

## 検証

- バージョン連続性: v2 2.0.0–2.0.27 と v1 1.18.8–1.18.35 + 1.19.0 がすべて棚上がり（Push260803 → 本タグ）。
- `SHA256SUMS.txt` は 35 パッケージを網羅: `sha256sum -c SHA256SUMS.txt`。
- 世代跨ぎマトリクス: `opencode`（v2）と `opencode1`（v1）は同時インストール可能、世代別ランチャーでデータ分離。
