# Push260930 — RC5：B1（native-gnu）確定

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260930) · [中文](/zh_CN/wiki/opencode-termux/release/Push260930.md)

## 概要

[RFC discussions/29](https://github.com/Hope2333/opencode-termux/discussions/29) に基づき、**RC5 = B1（native-gnu）確定**です：
v2 native 全 19 バージョン（2.0.0-2.0.18）を**上流 gnu PTY アセットをそのまま**使って再ビルド（**PKGREL=5**）し、seccomp shim も引き続き全パッケージに同梱（#17/#24 の修正はリグレッションなし）。2 ライン計画で最初に確定したファミリーです — RC6 で B2（native-musl）を確定します。

**38 アセット**（v2 native 19 バージョン、deb + pacman）、アセットごとのダイジェスト検証済み。

| 比較 | B1（本 RC5） | B2（RC4 で提供 / RC6 で確定） |
|---------|---------------|----------------------------------------|
| PTY ヘルパー | 上流 gnu バリアントをそのまま使用（連続性） | 完全静的 musl バリアント（#27 修正） |
| ランタイム | 大多数の環境（ゼロ glibc 含む）で安定 | 脆弱なカーネルを含む全環境で頑健 |
| 純度 | glibc 要素を含む | glibc 混入ゼロ |

**相互排他**：B1 と B2 は同一世代内でどちらか 1 つを選択。wrapper／compressed とも相互排他で、世代をまたぐ v1 は共存可能。`*-standalone` は共存の例外です。

## インストール

```bash
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

pacman -S opencode    # v2 メインライン（本リリース = B1 gnu 確定、PKGREL=5）
pacman -S opencode1   # v1 メインライン（v2 と共存）
```

手動（バージョン指定）：`pacman -U opencode-2.0.18-5-aarch64.pkg.tar.xz`
