# Push260928 — RC4 修正・補完

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260928)

## 概要

RC4 = RC3 の両世代ファミリーを**修正・補完**したものです — **計画 84 アセット**（site-rebuild 自己修復による repo db／mirrorlist を除く）：

- **seccomp shim を全 v2 native パッケージに同梱**（#17/#24 の修正：4.19 など旧カーネルでの `Bad system call`）— v2 native 全ラインを **PKGREL=4** で再ビルドし、`harden-native` をチェーンに組み込み
- **PTY ヘルパーを上流公式の musl 完全静的版に切り替え**（#27 の修正：glibc ABI は bionic ではロードできない）— ビルドごとに埋め込みハッシュのアサーションを実施
- **範囲補完**：v2.0.13–2.0.17（B ライン）と v1.18.33（A ライン）を追加
- **stale-serve-kill インストールフック**は v2 2.0.[0-3] のみ同梱（パッケージングフックレジストリ：`HOOKS_ENABLE` / `HOOKS_DISABLE` + バージョン範囲デフォルト；2.0.0 で発火、2.0.5 で非発火を検証済み）

| ファミリー | 世代 | パッケージ | 形式 | 備考 |
|--------|-----------|---------|--------|-------|
| native（メインライン） | v2 | `opencode` | deb + pacman `.pkg.tar.xz` | ゼロ glibc bionic ELF；PKGREL=4、shim + musl pty 同梱 |
| native（メインライン） | v1 | `opencode1` | deb + pacman `.pkg.tar.xz` | ゼロ glibc bionic ELF、直接実行 |
| wrapper（付録） | v2 | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | bun-termux-loader wrap |
| wrapper（付録） | v1 | `opencode1-wrapper` | deb + pacman `.pkg.tar.xz` | glibc ランタイム payload |
| compressed（UPX） | v1 | `opencode1-compressed` | deb + pacman `.pkg.tar.gz` | UPX 圧縮は外部委託、opencode-compressed-branch 参照 |

**相互排他**：世代をまたいで `opencode1`（v1）と `opencode`（v2）は**共存可能**です。同一世代内では native / wrapper / compressed のうち**必ず 1 つだけ**インストールしてください。

バージョン範囲：v2 native 19 バージョン（2.0.0–2.0.18）／ v2 wrapper 13（2.0.0–2.0.12）／ v1 native 4（1.18.30–33）／ v1 wrapper & compressed 各 3（1.18.30–32）。

## インストール

### ソフトウェアソースの設定（1 回だけ）

```bash
# ワンライナー：ソース設定とインストール（pacman + apt を一気に）
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode
```

### ソースからインストール（apt / pacman）

```bash
# v2 メインライン
pacman -S opencode            # または opencode-wrapper
apt update && apt install opencode
# v1 メインライン（v2 と共存）
pacman -S opencode1           # または opencode1-wrapper / opencode1-compressed
apt update && apt install opencode1
```

### 手動インストール（バージョン指定）

```bash
pacman -U opencode-2.0.18-4-aarch64.pkg.tar.xz              # v2 native（PKGREL=4、shim 同梱）
pacman -U opencode1-1.18.33-3-aarch64.pkg.tar.xz            # v1 native（PKGREL=3）
pacman -U opencode1-compressed-1.18.32-3-aarch64.pkg.tar.gz # v1 compressed（.gz に注意）
dpkg -i opencode_2.0.18_aarch64.deb
dpkg -i opencode1_1.18.33_aarch64.deb
```

> deb には pkgrel の概念がありません（--clobber で上書き）；v2 native の pacman 製品は `-4-`、その他のファミリーはすべて `-3-` が入ります。
