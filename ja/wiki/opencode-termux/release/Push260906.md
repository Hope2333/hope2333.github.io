# Push260906 — 正式リリース

3 ファミリー × 2 形式のパッケージ列車。Push260903 を置き換えます。

## 新着情報

- 13 バージョン（1.18.15–1.18.27）× 3 ファミリー × 2 形式 = 78 パッケージ
- Native メインライン：純 Bionic、ゼロ glibc、seccomp SIGSYS shim、TUI、bin-direct
- Glibc 付録：bin-only パッケージング（単一バイナリ、メンテナーフックなし）、自己完結コンポジット（Termux の glibc パッケージ不要）
- Compressed ファミリー：UPX 圧縮ランタイム、gzip fast-wrap パッケージ、常に `libopencode-crhandler.so` を同梱
- UPX ランタイムアセット：`opencode-native-<ver>-upx.xz`（13 件）
- SHA256SUMS.txt：検証済み 91 エントリ
- 最新：v1.18.27
