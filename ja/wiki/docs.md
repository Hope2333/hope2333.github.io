# プロジェクトドキュメントリンク集

> hope2333 プロジェクトの公式ドキュメントへの入口まとめ。ドキュメントの原文言語どおりに収録

このページは各プロジェクトの公式ドキュメントへの直接リンクをまとめたものです。リンクは常に**ドキュメントの原文**を指します（中国語のドキュメントは中国語へ、英語のドキュメントは英語へ）。本サイトの翻訳コピーは経由しません。収録時に全リンクの到達可能性（HTTP 200）を実測済みです。利用可能なドキュメントがないプロジェクトにはリンクを設けず、捏造もしません。
