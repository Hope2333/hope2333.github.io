pacman リポジトリ（Termux）

統一 [hope2333] リポジトリ + hope2333-mirrorlist パッケージで、当サイトが公開している Termux パッケージをインストールします。

推奨手順（統一リポジトリ + mirrorlist パッケージ）

  1. 統一セクションを $PREFIX/etc/pacman.conf の末尾に追記します：
[hope2333]
Server = https://github.com/Hope2333/codegraph-termux/releases/latest/download/
Server = https://github.com/Hope2333/opencode-termux/releases/latest/download/
Server = https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/
Server = https://github.com/Hope2333/freebuff-termux/releases/latest/download/
Server = https://github.com/Hope2333/codebuff-termux/releases/latest/download/
Server = https://hope2333.github.io/repo/Termux/pacman/
SigLevel = Optional TrustAll
  1. mirrorlist パッケージをインストールします：pacman -Sy && pacman -S hope2333-mirrorlist；
  2. インストール後、パッケージのフックが手動セクションを Include = /etc/pacman.d/hope2333-mirrorlist.conf の 1 行に置き換えます（管理対象 conf 自体がセクションヘッダと Server/SigLevel を持つため、pacman.conf 側に同名セクションを残すと二重登録で Server が失われます）。以降のリポジトリ変更はパッケージ更新時に反映されます。

設定が完了すれば、パッケージをインストールできます。例：pacman -S codegraph。

旧形式の [hope2333-meta] ブートストラップセクションや旧 [hope2333] ブロック（Server 1 行・複数行を問わず）が残っている場合は、追記せず丸ごとこの統一セクションに置き換えてください — 二重登録すると database already registered エラーになります。あるいは install.sh を再実行すれば自動移行されます。

統一 db（hope2333.db.tar.gz）には 5 リポジトリ全パッケージと hope2333-mirrorlist が収録され、当サイトと各 Release CDN にホストされています。パッケージファイルは Server の順に 1 ファイルずつフォールバックし、最終的に GitHub Release CDN からダウンロードされます（302 は自動追従）。MiMoCode はプレリリースチャネルで、Push260829 に明示的にピン留めされています。v1 のリポジトリは未署名のため Optional TrustAll。今後 repo-add -s への移行を予定しています。
