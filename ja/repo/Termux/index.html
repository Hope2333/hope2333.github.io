Termux 手動設定 · Hope2333

まずワンクリックスクリプトの利用を推奨します：/ja/repo/ install.sh（Termux を自動判定、統一リポジトリを設定し hope2333-mirrorlist パッケージをインストール、旧設定を自動移行、冪等）。以下は手動設定の手順です。

pacman リポジトリ設定（統一リポジトリ + mirrorlist パッケージ）

  1. 統一セクションを $PREFIX/etc/pacman.conf の末尾に追記します：
[hope2333]
Server = https://github.com/Hope2333/codegraph-termux/releases/latest/download/
Server = https://github.com/Hope2333/opencode-termux/releases/latest/download/
Server = https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/
Server = https://github.com/Hope2333/freebuff-termux/releases/latest/download/
Server = https://github.com/Hope2333/codebuff-termux/releases/latest/download/
Server = https://hope2333.github.io/repo/Termux/pacman/
SigLevel = Optional TrustAll
  1. mirrorlist パッケージをインストールします：pacman -Sy && pacman -S hope2333-mirrorlist（インストール後、パッケージのフックが手動セクションを Include = /etc/pacman.d/hope2333-mirrorlist.conf の 1 行に置き換えます — 管理対象 conf 自体がセクションヘッダと Server/SigLevel を持つため、pacman.conf 側に同名セクションを残すと二重登録で Server が失われます。以降のリポジトリ変更はパッケージ更新時に反映されます）

旧形式の [hope2333-meta] ブートストラップセクションや旧 [hope2333] ブロック（Server 1 行・複数行を問わず）が残っている場合は、追記せず丸ごとこの統一セクションに置き換えてください — 二重登録すると database already registered エラーになります。あるいは install.sh を再実行すれば自動移行されます。

APT リポジトリ設定（ブートストラップリポジトリ + mirrorlist パッケージ）

  1. ブートストラップ行を $PREFIX/etc/apt/sources.list.d/hope2333-bootstrap.list に書き込みます：
deb [trusted=yes arch=aarch64] https://hope2333.github.io/repo/Termux/apt/ ./
  1. mirrorlist パッケージをインストールします：apt update && apt install hope2333-mirrorlist（パッケージが hope2333.list を書き込みます — 各リポジトリの Release latest を指す 5 行の flat 形式）

旧 deb .../repo/Termux/apt/ stable main 行は無効です（io は apt リポジトリをホストしていません）。削除するかブートストラップ行に置き換えてください。

手動設定（hope2333-mirrorlist パッケージをインストールしない場合） 
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/codegraph-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/opencode-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/freebuff-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/codebuff-termux/releases/latest/download/ ./

統一リポジトリセクションの内容は hope2333-mirrorlist パッケージと一致しています。MiMoCode はプレリリースチャネルで、Push260829 に明示的にピン留めされています（GitHub は prerelease を Latest にできないため、releases/latest は 404 になります）。

署名検証（repo-add -s / Release 署名）は今後導入予定です。現状の v1 は未署名です。
