Repositorio pacman (Termux)

Instale los paquetes Termux publicados en este sitio mediante el repo unificado [hope2333] + el paquete hope2333-mirrorlist.

Flujo recomendado (repo unificado + paquete mirrorlist)

  1. Añada la sección unificada al final de $PREFIX/etc/pacman.conf:
[hope2333]
Server = https://github.com/Hope2333/codegraph-termux/releases/latest/download/
Server = https://github.com/Hope2333/opencode-termux/releases/latest/download/
Server = https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/
Server = https://github.com/Hope2333/freebuff-termux/releases/latest/download/
Server = https://github.com/Hope2333/codebuff-termux/releases/latest/download/
Server = https://hope2333.github.io/repo/Termux/pacman/
SigLevel = Optional TrustAll
  1. Instale el paquete mirrorlist: pacman -Sy && pacman -S hope2333-mirrorlist;
  2. Tras la instalación, el hook del paquete sustituye la sección manual por una única línea Include = /etc/pacman.d/hope2333-mirrorlist.conf (el conf gestionado ya incluye su propio encabezado de sección y las líneas Server/SigLevel; conservar una sección con el mismo nombre en pacman.conf la registraría dos veces y se perderían los Server). Los cambios de repo surten efecto a través de las actualizaciones del paquete.

Con la configuración lista, ya puede instalar paquetes, p. ej. pacman -S codegraph.

Si conserva la sección de arranque antigua [hope2333-meta] o un bloque [hope2333] anterior (con uno o varios Server): sustitúyalo por completo por esta sección unificada, no lo añada — el registro duplicado falla con database already registered; o simplemente vuelva a ejecutar install.sh para migrar automáticamente.

El db unificado (hope2333.db.tar.gz) recoge los paquetes de los cinco repos más hope2333-mirrorlist, alojado en este sitio y en cada Release CDN; los archivos de paquetes se recuperan archivo por archivo en orden de Server y se descargan finalmente del GitHub Release CDN (los 302 se siguen automáticamente). MiMoCode es un canal de prelanzamiento fijado explícitamente a Push260829. El repo v1 no está firmado, de ahí Optional TrustAll; está previsto migrar a repo-add -s.
