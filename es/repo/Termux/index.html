Hope2333 · Termux

Configuración manual de Termux · Hope2333

Se recomienda probar primero el script de un solo paso: /es/repo/ install.sh (detecta Termux automáticamente, configura el repo unificado, instala el paquete hope2333-mirrorlist, migra la configuración antigua, idempotente). A continuación se describe la configuración manual.

Configuración del repo pacman (repo unificado + paquete mirrorlist)

  1. Añada la sección unificada al final de $PREFIX/etc/pacman.conf:
[hope2333]
Server = https://github.com/Hope2333/codegraph-termux/releases/latest/download/
Server = https://github.com/Hope2333/opencode-termux/releases/latest/download/
Server = https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/
Server = https://github.com/Hope2333/freebuff-termux/releases/latest/download/
Server = https://github.com/Hope2333/codebuff-termux/releases/latest/download/
Server = https://hope2333.github.io/repo/Termux/pacman/
SigLevel = Optional TrustAll
  1. Instale el paquete mirrorlist: pacman -Sy && pacman -S hope2333-mirrorlist (tras la instalación, el hook del paquete sustituye la sección manual por una única línea Include = /etc/pacman.d/hope2333-mirrorlist.conf — el conf gestionado ya incluye su propio encabezado de sección y las líneas Server/SigLevel; conservar una sección con el mismo nombre en pacman.conf la registraría dos veces y se perderían los Server. Los cambios de repo surten efecto a través de las actualizaciones del paquete)

Si conserva la sección de arranque antigua [hope2333-meta] o un bloque [hope2333] anterior (con uno o varios Server): sustitúyalo por completo por esta sección unificada, no lo añada — el registro duplicado falla con database already registered; o simplemente vuelva a ejecutar install.sh para migrar automáticamente.

Configuración del repo APT (repo de arranque + paquete mirrorlist)

  1. Escriba la línea de arranque en $PREFIX/etc/apt/sources.list.d/hope2333-bootstrap.list:
deb [trusted=yes arch=aarch64] https://hope2333.github.io/repo/Termux/apt/ ./
  1. Instale el paquete mirrorlist: apt update && apt install hope2333-mirrorlist (el paquete escribe hope2333.list — 5 líneas flat que apuntan al Release latest de cada repo)

La línea antigua deb .../repo/Termux/apt/ stable main ya no es válida (io ya no aloja el repo apt); elimínela o sustitúyala por la línea de arranque.

La sección del repo unificado coincide con el contenido del paquete hope2333-mirrorlist; MiMoCode es un canal de prelanzamiento fijado explícitamente a Push260829 (GitHub no permite que un prerelease sea Latest, por lo que releases/latest daría 404).

La verificación de firmas (repo-add -s / firmas de Release) se introducirá más adelante; la v1 actualmente no está firmada.
