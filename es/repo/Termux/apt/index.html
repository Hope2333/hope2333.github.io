Repositorio APT (Termux)

Instale los paquetes Termux publicados en este sitio mediante el repo de arranque + el paquete hope2333-mirrorlist.

Flujo recomendado (repo de arranque + paquete mirrorlist)

  1. Escriba la línea de arranque en $PREFIX/etc/apt/sources.list.d/hope2333-bootstrap.list:
deb [trusted=yes arch=aarch64] https://hope2333.github.io/repo/Termux/apt/ ./
  1. Instale el paquete mirrorlist: apt update && apt install hope2333-mirrorlist;
  2. El paquete escribe hope2333.list (5 líneas flat que apuntan al Release latest de cada repo); los cambios de repo surten efecto a través de las actualizaciones del paquete.

Con la configuración lista, ya puede instalar paquetes, p. ej. apt install codegraph.

La línea antigua deb .../repo/Termux/apt/ stable main ya no es válida (io ya no aloja el repo apt); elimínela o sustitúyala por la línea de arranque.

Configuración manual (respaldo)

Desplegar los repos flat de 5 líneas (sin instalar hope2333-mirrorlist) 
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/codegraph-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/opencode-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/freebuff-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/codebuff-termux/releases/latest/download/ ./

Esto funciona siempre que el release de cada repo fuente proporcione Packages.gz (termux-asset-update v7.2); hasta entonces las líneas flat devuelven 404. Este sitio (io) ya no aloja ningún archivo de paquetes. MiMoCode es un canal de prelanzamiento fijado explícitamente a Push260829.
