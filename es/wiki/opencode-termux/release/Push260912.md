# Push260912 — Versión formal de opencode-wrapper

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260912)

## Resumen

El ciclo rolling de tags Push completa el **renombrado `opencode-glibc` → `opencode-wrapper`** y llena la matriz de cuatro familias. Versión **v1.18.30**.

| Familia | Nombre del paquete | Formato | Descripción |
|--------|-------------|--------|-------------|
| native (línea principal) | `opencode` | deb + pacman `.pkg.tar.xz` | ELF bionic sin glibc, ejecuta directamente |
| wrapper (apéndice) | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | Wrapper glibc — renombrado desde `opencode-glibc` |
| compressed (empaquetada) | `opencode-compressed` | deb + pacman `.pkg.tar.gz` | Empaquetado con UPX --best |
| standalone (rollback) | `opencode-wrapper-standalone` | deb + pacman `.pkg.tar.xz` | Rollback de versión única congelada, coexiste con `opencode` |

También publica `SHA256SUMS.txt` (verificación completa) y `Packages.gz` (índice de fuente flat de apt).

## Renombrado de paquete: opencode-glibc → opencode-wrapper

La familia apéndice glibc pasa a llamarse `opencode-wrapper`:

- **deb**: `Replaces: opencode-glibc` + `Breaks: opencode-glibc (<< version)` — los usuarios actuales de `opencode-glibc` **se actualizan automáticamente** a `opencode-wrapper`, sin acción manual.
- **pacman**: `replaces=('opencode-glibc')` — la misma semántica de actualización automática.

**Exclusión mutua**: `opencode` ↔ `opencode-wrapper` son mutuamente excluyentes; `opencode-compressed` hace Provides de `opencode`, de modo que solo uno de los tres puede estar instalado. `opencode-wrapper-standalone` es mutuamente excluyente con `opencode-wrapper`, pero coexiste con `opencode` (solo como vía de rollback).

## Instalación

### Configuración de la fuente (una sola vez)

```bash
# Un solo paso: configura las fuentes e instala (fuentes pacman + apt listas)
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

# O manualmente:
# pacman — añade la sección unificada [hope2333] a $PREFIX/etc/pacman.conf (bloque completo en
#   el bloque de configuración manual de /repo/Termux/), luego pacman -Sy && pacman -S hope2333-mirrorlist
#   (el hook posterior a la instalación convierte la sección a la forma cabecera + Include)
# apt — escribe en $PREFIX/etc/apt/sources.list.d/hope2333.list:
#   deb [trusted=yes arch=aarch64] https://github.com/Hope2333/opencode-termux/releases/latest/download/ ./
```

### Instalación desde la fuente (apt / pacman, la más reciente de cada paquete)

```bash
pacman -S opencode              # línea principal nativa
pacman -S opencode-wrapper      # apéndice wrapper (renombrado desde opencode-glibc)
pacman -S opencode-compressed   # empaquetado con UPX

apt update && apt install opencode-compressed   # u opencode / opencode-wrapper
```

> El índice flat de apt (`Packages.gz`) solo contiene la **versión más reciente** de cada nombre de paquete.
> Para instalar una versión antigua concreta, usa la instalación manual de abajo, descargando directamente los assets del release.

### Instalación manual (versión concreta)

```bash
pacman -U opencode-<ver>-1-aarch64.pkg.tar.xz             # native / wrapper
dpkg    -i opencode_<ver>_aarch64.deb
pacman -U opencode-compressed-<ver>-1-aarch64.pkg.tar.gz  # comprimida (ojo al .gz)
dpkg    -i opencode-compressed_<ver>_aarch64.deb
pacman -U opencode-wrapper-standalone-<ver>-1-aarch64.pkg.tar.xz  # rollback standalone
dpkg    -i opencode-wrapper-standalone_<ver>_aarch64.deb
```
