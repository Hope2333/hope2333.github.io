# Push260930 — RC5: B1 (native-gnu) finalizado

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260930) · [中文](/zh_CN/wiki/opencode-termux/release/Push260930.md)

## Resumen

**RC5 = B1 (native-gnu) finalizado** según las [discusiones RFC/29](https://github.com/Hope2333/opencode-termux/discussions/29):
las 19 versiones v2 nativas (2.0.0-2.0.18) se recompilaron con el **asset PTY gnu upstream
mantenido tal cual** (**PKGREL=5**), conservando el shim seccomp en todos los
paquetes (sin regresión de las correcciones #17/#24). Primera familia finalizada del plan
de doble línea — RC6 finalizará B2 (native-musl).

**38 assets** (v2 nativa 19 versiones, deb + pacman), con digest verificado por asset.

| Comparativa | B1 (este RC5) | B2 (publicada en RC4 / finalizada en RC6) |
|---------|---------------|----------------------------------------|
| Helper PTY | variante gnu upstream tal cual (continuidad) | variante musl totalmente estática (corrección #27) |
| Runtime | estable en la gran mayoría de entornos (incl. cero-glibc) | robusto en todos los entornos, incl. kernels frágiles |
| Pureza | contiene un elemento glibc | contaminación glibc cero |

**Exclusión mutua**: entre B1 y B2 se elige una dentro de la generación; también es
mutuamente excluyente con wrapper/compressed; entre generaciones coexiste la v1;
`*-standalone` es la excepción de coexistencia.

## Instalación

```bash
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

pacman -S opencode    # línea principal v2 (este release = B1 gnu finalizado, PKGREL=5)
pacman -S opencode1   # línea principal v1 (coexiste con la v2)
```

Manual (fijado): `pacman -U opencode-2.0.18-5-aarch64.pkg.tar.xz`
