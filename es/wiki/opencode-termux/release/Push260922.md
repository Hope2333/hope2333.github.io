# Push260922 — RC3: Refresco completo de familias en dos generaciones

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260922)

## Resumen

RC3 es una reconstrucción desde cero: los 69 assets originales de Push260922 se purgaron y la
familia completa de dos generaciones se recompiló y resubió con **PKGREL=3** (tercer marcador
de release) — **70 assets previstos** en total (más la db del repo y el mirrorlist
auto-reparados por site-rebuild). Las compilaciones antiguas propensas a fallos de la era
bun-1.4.2 y los paquetes caducados desaparecieron de un barrido; todo se compiló desde el HEAD
más reciente del repositorio.

| Familia | Generación | Paquete | Formato | Notas |
|--------|-----------|---------|--------|-------|
| native (línea principal) | v2 | `opencode` | deb + pacman `.pkg.tar.xz` | ELF bionic sin glibc, ejecución directa |
| native (línea principal) | v1 | `opencode1` | deb + pacman `.pkg.tar.xz` | ELF bionic sin glibc, ejecución directa |
| wrapper (apéndice) | v2 | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | Wrap de bun-termux-loader |
| wrapper (apéndice) | v1 | `opencode1-wrapper` | deb + pacman `.pkg.tar.xz` | Payload runtime glibc |
| compressed (UPX) | v1 | `opencode1-compressed` | deb + pacman `.pkg.tar.gz` | Compresión subcontratada a UPX (ver opencode-compressed-branch) |

**Exclusión mutua**: entre generaciones, `opencode1` (v1) y `opencode` (v2) SÍ pueden
coexistir en paralelo; dentro de la misma generación instala exactamente UNO de
native / wrapper / compressed.

Cobertura de versiones: v2 native y wrapper 13 versiones cada uno (2.0.0–2.0.12) +
v1 tres familias × 3 versiones (1.18.30–32).

## Instalación

### Configurar el repositorio de software (una sola vez)

```bash
# Un solo paso: configura las fuentes e instala (pacman + apt de una vez)
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode
```

### Instalar desde el repositorio (apt / pacman, dos generaciones coexisten)

```bash
# Línea principal v2
pacman -S opencode            # u opencode-wrapper
apt update && apt install opencode
# Línea principal v1 (coexiste con la v2)
pacman -S opencode1           # u opencode1-wrapper / opencode1-compressed
apt update && apt install opencode1
```

### Instalación manual (versión fijada)

```bash
pacman -U opencode-2.0.12-3-aarch64.pkg.tar.xz              # v2 nativa (PKGREL=3)
pacman -U opencode1-1.18.32-3-aarch64.pkg.tar.xz            # v1 nativa (PKGREL=3)
pacman -U opencode1-compressed-1.18.32-3-aarch64.pkg.tar.gz # v1 comprimida (ojo al .gz)
dpkg -i opencode_2.0.12_aarch64.deb
dpkg -i opencode1_1.18.32_aarch64.deb
```

> deb no tiene concepto de pkgrel — la versión no cambia (sobrescritura --clobber); los
> artefactos pac llevan `-3-` en el nombre de archivo.
