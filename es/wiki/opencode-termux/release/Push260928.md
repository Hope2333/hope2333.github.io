# Push260928 — RC4: Correcciones y cierre

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260928)

## Resumen

RC4 = la familia de dos generaciones de RC3, **corregida y completada** — **84 assets
previstos** (más la db del repo y el mirrorlist vía auto-reparación de site-rebuild):

- **El shim seccomp se incluye en todos los paquetes v2 nativos** (corrige #17/#24:
  `Bad system call` en kernels antiguos como el 4.19) — toda la línea v2 nativa
  recompilada como **PKGREL=4** con `harden-native` cableado en la cadena
- **El helper PTY pasa a la variante musl totalmente estática oficial upstream**
  (corrige #27: el ABI glibc no puede cargarse bajo bionic) — aserción de hash
  embebido por compilación tras cada build
- **Cierre de rango**: se añaden v2.0.13–2.0.17 (línea B) y v1.18.33 (línea A)
- **El hook de instalación stale-serve-kill se incluye solo en v2 2.0.[0-3]**
  (registro de hooks de empaquetado: `HOOKS_ENABLE` / `HOOKS_DISABLE` + valores por
  rango de versión; verificado que dispara en 2.0.0 y no dispara en 2.0.5)

| Familia | Generación | Paquete | Formato | Notas |
|--------|-----------|---------|--------|-------|
| native (línea principal) | v2 | `opencode` | deb + pacman `.pkg.tar.xz` | ELF bionic sin glibc; PKGREL=4, shim + pty musl embebidos |
| native (línea principal) | v1 | `opencode1` | deb + pacman `.pkg.tar.xz` | ELF bionic sin glibc, ejecución directa |
| wrapper (apéndice) | v2 | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | Wrap de bun-termux-loader |
| wrapper (apéndice) | v1 | `opencode1-wrapper` | deb + pacman `.pkg.tar.xz` | Payload runtime glibc |
| compressed (UPX) | v1 | `opencode1-compressed` | deb + pacman `.pkg.tar.gz` | Compresión subcontratada a UPX, ver opencode-compressed-branch |

**Exclusión mutua**: entre generaciones, `opencode1` (v1) y `opencode` (v2) SÍ pueden
coexistir en paralelo; dentro de la misma generación instala exactamente UNO de
native / wrapper / compressed.

Cobertura de versiones: v2 native 19 versiones (2.0.0–2.0.18) / v2 wrapper 13
(2.0.0–2.0.12) / v1 native 4 (1.18.30–33) / v1 wrapper y compressed 3 cada una
(1.18.30–32).

## Instalación

### Configurar el repositorio de software (una sola vez)

```bash
# Un solo paso: configura las fuentes e instala (pacman + apt de una vez)
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode
```

### Instalar desde el repositorio (apt / pacman)

```bash
# Línea principal v2
pacman -S opencode            # u opencode-wrapper
apt update && apt install opencode
# Línea principal v1 (coexiste con la v2)
pacman -S opencode1           # u opencode1-wrapper / opencode1-compressed
apt update && apt install opencode1
```

### Instalación manual (versión fijada)

```bash
pacman -U opencode-2.0.18-4-aarch64.pkg.tar.xz              # v2 nativa (PKGREL=4, shim incluido)
pacman -U opencode1-1.18.33-3-aarch64.pkg.tar.xz            # v1 nativa (PKGREL=3)
pacman -U opencode1-compressed-1.18.32-3-aarch64.pkg.tar.gz # v1 comprimida (ojo al .gz)
dpkg -i opencode_2.0.18_aarch64.deb
dpkg -i opencode1_1.18.33_aarch64.deb
```

> deb no tiene concepto de pkgrel (sobrescritura --clobber); los nombres pac de v2 nativa llevan
> `-4-`, todas las demás familias `-3-`.
