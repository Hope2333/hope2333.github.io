# MiMoCode-Termux

> MiMoCode for Termux, based on opencode-termux

## Introducción

MiMoCode for Termux, construido sobre opencode-termux. El proyecto lleva MiMoCode a la plataforma Termux, reutilizando en su implementación el trabajo ya realizado por opencode-termux.

## Instalación

Este proyecto aún no está en el repositorio de software de hope2333; obténlo desde el [repositorio de GitHub](https://github.com/Hope2333/MiMoCode-Termux). Las instrucciones de instalación están en el README del repositorio.
