# bun-termux

> Bun runtime for Termux

## Introducción

Bun runtime for Termux. El proyecto proporciona el runtime de Bun para la plataforma Termux, facilitando la ejecución de Bun y de las herramientas de su ecosistema en dispositivos Android.

## Instalación

Este proyecto aún no está en el repositorio de software de hope2333; obténlo desde el [repositorio de GitHub](https://github.com/Hope2333/bun-termux). Las instrucciones de instalación están en el README del repositorio.
