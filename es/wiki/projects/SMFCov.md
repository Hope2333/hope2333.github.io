# SMFCov

> Shell-based media converter

## Introducción

Shell-based media converter. SMFCov es una herramienta de conversión de formatos multimedia basada en Shell, que encadena mediante scripts los flujos de conversión multimedia más habituales.

## Instalación

Este proyecto aún no está en el repositorio de software de hope2333; obténlo desde el [repositorio de GitHub](https://github.com/Hope2333/SMFCov). Las instrucciones de instalación están en el README del repositorio.
