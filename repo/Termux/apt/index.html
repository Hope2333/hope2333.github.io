APT 软件源（Termux）

通过自建 apt 源安装本站发布的 Termux 软件包。

客户端配置

deb [trusted=yes arch=aarch64] https://hope2333.github.io/repo/Termux/apt/ stable main

使用步骤

  1. 将上面的行写入 $PREFIX/etc/apt/sources.list.d/hope2333.list；
  2. 运行 apt update 刷新软件源索引；
  3. 安装软件包，例如 apt install codegraph。
