APT 软件源（Termux）

通过引导源 + hope2333-mirrorlist 包安装本站发布的 Termux 软件包。

推荐流程（引导源 + mirrorlist 包）

  1. 将引导行写入 $PREFIX/etc/apt/sources.list.d/hope2333-bootstrap.list：
deb [trusted=yes arch=aarch64] https://hope2333.github.io/repo/Termux/apt/ ./
  1. 安装 mirrorlist 包：apt update && apt install hope2333-mirrorlist；
  2. 包内写入 hope2333.list（5 行 flat，指向各仓 Release latest），此后源变更随包升级生效。

配置完成后即可安装软件包，例如 apt install codegraph。

旧 deb .../repo/Termux/apt/ stable main 行已失效（io 不再托管 apt 仓），请移除或替换为引导行。

手动配置（备用）

展开 5 行 flat 源（不装 hope2333-mirrorlist 包） 
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/codegraph-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/opencode-termux/releases/latest/download/ ./
deb [trusted=yes arch=aarch64] https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/ ./

生效依赖各源仓 release 提供 Packages.gz（termux-asset-update v7.2），落地前 flat 行 404；本站（io）不再托管任何包文件 MiMoCode 为预发布渠道，显式钉 Push260829。
