Pacman 软件源（Termux）

通过统一 [hope2333] 源 + hope2333-mirrorlist 包安装本站发布的 Termux 软件包。

推荐流程（统一源 + mirrorlist 包）

  1. 将统一节追加到 $PREFIX/etc/pacman.conf 末尾：
[hope2333]
Server = https://github.com/Hope2333/codegraph-termux/releases/latest/download/
Server = https://github.com/Hope2333/opencode-termux/releases/latest/download/
Server = https://github.com/Hope2333/MiMoCode-Termux/releases/download/Push260829/
Server = https://github.com/Hope2333/freebuff-termux/releases/latest/download/
Server = https://github.com/Hope2333/codebuff-termux/releases/latest/download/
Server = https://hope2333.github.io/repo/Termux/pacman/
SigLevel = Optional TrustAll
  1. 安装 mirrorlist 包：pacman -Sy && pacman -S hope2333-mirrorlist；
  2. 包安装后钩子把该节收敛为 节头 + Include = /etc/pacman.d/hope2333-mirrorlist.conf（Server/SigLevel 移入包内托管 conf），此后源变更随包升级生效。

配置完成后即可安装软件包，例如 pacman -S codegraph。

已有旧版 [hope2333-meta] 引导节或旧 [hope2333] 块（单 Server 或多 Server）：整体替换为本统一节，勿追加——重复注册会报 database already registered；或直接重跑 install.sh 自动迁移。

统一 db（hope2333.db.tar.gz）收录五仓全部包 + hope2333-mirrorlist，托管在本站与各 Release CDN；包文件按 Server 顺序逐文件回退，最终从 GitHub Release CDN 下载（302 自动跟随）。MiMoCode 为预发布渠道，显式钉 Push260829。v1 源未签名，Optional TrustAll；后续 repo-add -s 升级。
