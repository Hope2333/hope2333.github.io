Hope2333 · Termux

Termux 专属手动配置 · Hope2333

推荐先用一键脚本：/repo/ install.sh（自动检测 Termux、配置 pacman 源、幂等）。以下为手动配置方式。

Pacman 源配置

[hope2333]
Server = https://hope2333.github.io/repo/Termux/pacman/
SigLevel = Optional TrustAll
  1. 将上方内容追加到 $PREFIX/etc/pacman.conf 末尾
  2. 运行 pacman -Syu 刷新索引
  3. 安装：pacman -S codegraph

APT 源配置

deb [trusted=yes arch=aarch64] https://hope2333.github.io/repo/Termux/apt/ stable main
  1. 将上方内容写入 $PREFIX/etc/apt/sources.list.d/hope2333.list
  2. 运行 apt update 刷新索引
  3. 安装：apt install codegraph

未来将引入签名校验（repo-add -s / Release 签名），当前 v1 无签名。
