# codegraph-termux

> Local-first code intelligence for AI agents (MCP)

## 簡介

Local-first code intelligence for AI agents（MCP）。項目爲 AI 代理提供本地優先的代碼智能能力，通過 MCP 協議接入，代碼索引與分析都在本地完成。

## 安裝

該項目已進入 hope2333 軟件源，在 Termux 中執行：

```sh
pacman -Sy codegraph
```
