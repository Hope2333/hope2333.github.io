# Push260930 — RC5：B1（native-gnu）定版

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push260930) · [English](/wiki/opencode-termux/release/Push260930.md)

## 概覽

**RC5 = B1（native-gnu）定版**（[RFC discussions/29](https://github.com/Hope2333/opencode-termux/discussions/29) 裁決）：v2 native 全 19 版（2.0.0-2.0.18）以 **gnu PTY 資產延續**重建上架（**PKGREL=5**），seccomp shim 照常隨包（#17/#24 修復不回退）。雙線並行第一支定版——RC6 將以 B2（native-musl）收口。

**38 件**（v2 native 19 版 deb + pacman），逐件 digest 對賬。

| 對比 | B1（本版 RC5） | B2（RC4 已上架 / RC6 定版） |
|------|---------------|------------------------------|
| PTY 助手 | 上游 gnu 變體原樣（延續現狀） | musl 全靜態變體（#27 修復） |
| 運行面 | 絕大多數環境穩定（含零 glibc） | 全環境含脆弱內核 |
| 純度 | 含 glibc 元素 | 零 glibc 沾染 |

**同代互斥**：B1 與 B2 二選一；與 wrapper/compressed 同代互斥；跨代 v1 可共存；`*-standalone` 爲共存例外。

## Install

```bash
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

pacman -S opencode    # v2 mainline（本版 = B1 gnu 定版，PKGREL=5）
pacman -S opencode1   # v1 mainline（跨代共存）
```

手動（釘版本）：`pacman -U opencode-2.0.18-5-aarch64.pkg.tar.xz`
