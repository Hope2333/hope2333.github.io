# Push261013 — 全家族批次：v2 2.0.23–2.0.27 + v1 1.18.35 / 1.19.0

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261013) · [中文版](/zh_CN/wiki/opencode-termux/release/Push261013.md) · [English](/en/wiki/opencode-termux/release/Push261013.md) · [Español](/es/wiki/opencode-termux/release/Push261013.md) · [日本語](/ja/wiki/opencode-termux/release/Push261013.md) · [繁體中文](/zh_TW/wiki/opencode-termux/release/Push261013.md)

## 概覽

**Push261013** 一次帶上遊 **v2 五版（2.0.23–2.0.27）** 與 **v1 兩版（1.18.35、1.19.0 新 minor 線）**，每版三族齊發：native、UPX 壓制 compressed、wrapper（**僅 deb**，沿用慣例）。全部為首次發布，rel 一律 **=1**。

**36 件**：35 包 + `SHA256SUMS.txt`（35 條）

| 家族 | 版本範圍 | 格式 | 數量 |
|------|----------|------|------|
| `opencode`（v2 native） | 2.0.23 – 2.0.27 | deb + `.pkg.tar.xz` | 5 + 5 |
| `opencode1`（v1 native） | 1.18.35、1.19.0 | deb + `.pkg.tar.xz` | 2 + 2 |
| `opencode-compressed` | 2.0.23 – 2.0.27 | deb + `.pkg.tar.gz` | 5 + 5 |
| `opencode1-compressed` | 1.18.35、1.19.0 | deb + `.pkg.tar.gz` | 2 + 2 |
| `opencode-wrapper` | 2.0.23 – 2.0.27 | 僅 deb | 5 |
| `opencode1-wrapper` | 1.18.35、1.19.0 | 僅 deb | 2 |

**建構譜系**：v2 native 走 B 線原始碼編譯（android bun），依賴釘版按上遊逐版對齊——opentui **0.5.14**（2.0.23/24）、**0.5.16**（2.0.25）、**0.5.17**（2.0.26/27），pty 統一 **0.2.0**；v1 native 走 transplant 復活線（bun 1.4.0 底座，`transplant.py predict` 七版全 OK）。壓製由入庫工具 `tools/compressed-one.sh` 完成（UPX -4，壓縮率 ≈ 31–38%）。每包上傳前過三道冒煙（`--version` 版本門 + `--dbpath --help` 隔離 + TUI probe），上傳後逐件核驗 state/size/sha256-digest。

**同代互斥**：同代內 native / wrapper / compressed 三選一；跨代 v1（`opencode1*`）與 v2（`opencode*`）可共存；`*-standalone` 為共存例外。

## 安裝

```bash
pacman -U ./opencode-2.0.27-1-aarch64.pkg.tar.xz
dpkg -i ./opencode_2.0.27_aarch64.deb
```

## 驗證

- 版本連續性：v2 2.0.0–2.0.27、v1 1.18.8–1.18.35 + 1.19.0 全庫存可追（Push260803 → 本 tag）
- `SHA256SUMS.txt` 覆蓋全部 35 包：`sha256sum -c SHA256SUMS.txt`
- 雙代矩陣：`opencode`（v2）與 `opencode1`（v1）可同裝，資料由分代 launcher 隔離
