# Push260912 — opencode-wrapper 正式發佈

[GitHub Release（英文版）](https://github.com/Hope2333/opencode-termux/releases/tag/Push260912)

## 概覽

滾動 Push tag 本輪完成 **包名更名 `opencode-glibc` → `opencode-wrapper`**，並補齊四大家族矩陣，版本 **v1.18.30**。

| Family | 包名 | 格式 | 說明 |
|--------|------|------|------|
| native（主線） | `opencode` | deb + pacman `.pkg.tar.xz` | 零 glibc bionic ELF，直跑 |
| wrapper（附錄） | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | glibc wrapper — 由 `opencode-glibc` 更名而來 |
| compressed（壓制） | `opencode-compressed` | deb + pacman `.pkg.tar.gz` | UPX --best 壓制 |
| standalone（回滾） | `opencode-wrapper-standalone` | deb + pacman `.pkg.tar.xz` | 凍結單版本回滾包，與 `opencode` 共存 |

另隨架 `SHA256SUMS.txt`（全量校驗）與 `Packages.gz`（apt flat 源索引）。

## 包名更名：opencode-glibc → opencode-wrapper

glibc 附錄家族更名爲 `opencode-wrapper`：

- **deb**：`Replaces: opencode-glibc` + `Breaks: opencode-glibc (<< 版本)` —— 既有
  `opencode-glibc` 用戶**自動升級**到 `opencode-wrapper`，無需手動操作。
- **pacman**：`replaces=('opencode-glibc')` —— 同樣的自動升級語義。

**互斥關係**：`opencode` ↔ `opencode-wrapper` 互斥；`opencode-compressed` Provides
`opencode`，三者裝其一。`opencode-wrapper-standalone` 與 `opencode-wrapper` 互斥，
但與 `opencode` 共存（僅回滾路徑）。

## Install

### 軟件源配置（一次性）

```bash
# 一键：配置源并安装（pacman + apt 源一并就位）
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

# 或手动：
# pacman — $PREFIX/etc/pacman.conf 追加统一 [hope2333] 节（完整写法见
#   /repo/Termux/ 手动配置块），随后 pacman -Sy && pacman -S hope2333-mirrorlist
#   （包安装后钩子把该节收敛为 节头 + Include 托管形态）
# apt — $PREFIX/etc/apt/sources.list.d/hope2333.list 写入：
#   deb [trusted=yes arch=aarch64] https://github.com/Hope2333/opencode-termux/releases/latest/download/ ./
```

### 軟件源安裝（apt / pacman 均可，均爲各包最新版）

```bash
pacman -S opencode              # native 主线
pacman -S opencode-wrapper      # wrapper 附录线（由 opencode-glibc 更名）
pacman -S opencode-compressed   # UPX 压制版

apt update && apt install opencode-compressed   # 或 opencode / opencode-wrapper
```

> apt flat 索引（`Packages.gz`）只收錄每個包名的**最新版**；
> 指定歷史版本請用下方手動安裝，從 release 資產直取。

### 手動安裝（指定版本）

```bash
pacman -U opencode-<ver>-1-aarch64.pkg.tar.xz             # native / wrapper
dpkg    -i opencode_<ver>_aarch64.deb
pacman -U opencode-compressed-<ver>-1-aarch64.pkg.tar.gz  # compressed（注意 .gz）
dpkg    -i opencode-compressed_<ver>_aarch64.deb
pacman -U opencode-wrapper-standalone-<ver>-1-aarch64.pkg.tar.xz  # standalone 回滚
dpkg    -i opencode-wrapper-standalone_<ver>_aarch64.deb
```
