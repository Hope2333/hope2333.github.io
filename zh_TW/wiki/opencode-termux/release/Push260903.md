## 三包互斥矩陣

```
opencode (native)  ↔  opencode-glibc  →  互斥，装时二选一
opencode (native)  +  opencode-glibc-standalone  →  可共存
```

## 安裝方式

### native（推薦，零 glibc 依賴）
```bash
# pacman
pacman -U opencode-<ver>-1-aarch64.pkg.tar.xz
# deb
dpkg -i opencode_<ver>_aarch64.deb
```

### glibc（附錄維護，需 glibc-repo）
```bash
# pacman
pacman -U opencode-glibc-<ver>-1-aarch64.pkg.tar.xz
# deb
dpkg -i opencode-glibc_<ver>_aarch64.deb
```
