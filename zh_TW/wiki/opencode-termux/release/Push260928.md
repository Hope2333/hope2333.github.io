# Push260928 — RC4 修復與補全

[GitHub Release（英文版）](https://github.com/Hope2333/opencode-termux/releases/tag/Push260928)

## 概覽

RC4 = RC3 雙代家族的**修正與補全**，共 **84 件計劃資產**（另有 repo db/mirrorlist 4 件由 site-rebuild 自愈回傳）：

- **seccomp shim 全線隨包**（修復 #17/#24：kernel 4.19 等老內核 `Bad system call`）——v2 native 全線 **PKGREL=4**，`harden-native` 接入 `family-v2-native` 鏈
- **PTY 助手換用上游官方 musl 全靜態變體**（修復 #27：glibc ABI 無法在 bionic 加載）——構建後逐版嵌入哈希斷言
- **區間補齊**：新增 v2.0.13–2.0.17（B 線）與 v1.18.33（A 線）
- **stale-serve-kill 安裝鉤子**僅隨 v2 2.0.[0-3]（packaging hook 註冊表：`HOOKS_ENABLE` / `HOOKS_DISABLE` + 版本區間默認；實測 2.0.0 發射 / 2.0.5 不發射）

| Family | 代際 | 包名 | 格式 | 說明 |
|--------|------|------|------|------|
| native（主線） | v2 | `opencode` | deb + pacman `.pkg.tar.xz` | 零 glibc bionic ELF；PKGREL=4，shim + musl pty 內嵌 |
| native（主線） | v1 | `opencode1` | deb + pacman `.pkg.tar.xz` | 零 glibc bionic ELF，直跑 |
| wrapper（附錄） | v2 | `opencode-wrapper` | deb + pacman `.pkg.tar.xz` | bun-termux-loader wrap |
| wrapper（附錄） | v1 | `opencode1-wrapper` | deb + pacman `.pkg.tar.xz` | glibc runtime payload |
| compressed（壓制） | v1 | `opencode1-compressed` | deb + pacman `.pkg.tar.gz` | UPX 外包壓制（見 opencode-compressed-branch） |

**互斥關係（雙代口徑）**：跨代 `opencode1`（v1）與 `opencode`（v2）**可雙裝共存**；同代 native / wrapper / compressed **三選一**。

版本覆蓋：v2 native 19 版（2.0.0–2.0.18）/ v2 wrapper 19 版（2.0.0–2.0.18）/ v1 native 4 版（1.18.30–33）/ v1 wrapper、compressed 各 3 版（1.18.30–32）。

## Install

### 軟件源配置（一次性）

```bash
# 一键：配置源并安装（pacman + apt 源一并就位）
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode
```

### 軟件源安裝（apt / pacman，雙代共存）

```bash
# v2 主线
pacman -S opencode            # 或 opencode-wrapper
apt update && apt install opencode
# v1 主线（与 v2 共存）
pacman -S opencode1           # 或 opencode1-wrapper / opencode1-compressed
apt update && apt install opencode1
```

### 手動安裝（指定版本）

```bash
pacman -U opencode-2.0.18-4-aarch64.pkg.tar.xz              # v2 native（PKGREL=4，含 shim）
pacman -U opencode1-1.18.33-3-aarch64.pkg.tar.xz            # v1 native（PKGREL=3）
pacman -U opencode1-compressed-1.18.32-3-aarch64.pkg.tar.gz # v1 compressed（注意 .gz）
dpkg -i opencode_2.0.18_aarch64.deb
dpkg -i opencode1_1.18.33_aarch64.deb
```

> deb 無 pkgrel 概念（--clobber 覆蓋）；v2 native pac 產物名帶 `-4-`，其餘族 `-3-`。
