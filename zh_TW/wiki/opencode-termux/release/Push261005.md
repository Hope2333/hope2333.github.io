# Push261005 — rc1：fleet B 線重建代（rel 重打，raw 原包）

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261005) · [English](/wiki/opencode-termux/release/Push261005.md)

## 概覽

**Push261005** 是 native 家族的整代重建（fleet B 線，**NDK r27c / 不 strip**），rel 已按「**前最大+1 / 新版=1**」規則重打（初始 `-90` 上傳已替換）。本代與舊 transplant 代**不同源**——上游版本號相同，工具鏈譜系換新。native deb 亦已按此代全量重打。

**57 件**：28 pacman + 28 deb + `SHA256SUMS.txt`

| 家族 | 版本範圍 | rel | 數量（pacman + deb） |
|------|----------|-----|----------------------|
| `opencode`（v2 native） | 2.0.0–2.0.10、2.0.12、2.0.15–2.0.18 | 6 | 16 + 16 |
| `opencode`（v2 native） | 2.0.11、2.0.13、2.0.14 | 5 | 3 + 3 |
| `opencode`（v2 native） | 2.0.19 – 2.0.22（新） | 1 | 4 + 4 |
| `opencode1`（v1 native） | 1.18.30 – 1.18.33 | 4 | 4 + 4 |
| `opencode1`（v1 native） | 1.18.34（新） | 1 | 1 + 1 |

**本批爲 raw 未壓縮原包**——UPX 壓制外包，**compressed 族後續產出後上傳到同一 tag**（一個滾動批次一個 tag）。wrapper 族 / glibc 族 / compressed 族**不在本批內**。

**同代互斥**：同代內 native / wrapper / compressed 三選一；跨代 v1（`opencode1*`）與 v2（`opencode*`）可共存；`*-standalone` 爲共存例外。

## 安裝

```bash
curl -fsSL https://hope2333.github.io/repo/install.sh | sh -s -- --install opencode

pacman -S opencode     # v2 主线（本批 = rel 重打，raw）
pacman -S opencode1    # v1 主线（与 v2 共存）
```

手動釘版：`pacman -U opencode-2.0.18-6-aarch64.pkg.tar.xz`
