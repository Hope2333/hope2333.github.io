# Push261103 — v2 2.0.32 → 2.2.5 與 v1 1.18.33 → 1.19.4

[GitHub Release](https://github.com/Hope2333/opencode-termux/releases/tag/Push261103) · [中文版](/zh_CN/wiki/opencode-termux/release/Push261103.md) · [English](/en/wiki/opencode-termux/release/Push261103.md) · [Español](/es/wiki/opencode-termux/release/Push261103.md) · [日本語](/ja/wiki/opencode-termux/release/Push261103.md) · [繁體中文](/zh_TW/wiki/opencode-termux/release/Push261103.md)

## 概覽

本批次一次補齊缺口：不再只發最新版，而是把兩代**全部已驗收版本**一起放出。

- **v2 native** — `2.0.32`、`2.1.0`–`2.1.4`、`2.2.0`–`2.2.5`（12 版）
- **v1 native** — `1.18.33`–`1.18.35`、`1.19.0`–`1.19.4`（8 版）

每版皆為 **deb + pacman**（`.pkg.tar.xz`）雙格式：**40 個套件 + SHA256SUMS.txt**。
全部是零 glibc 的 Android 原生二進位：上游原始碼以 android-bun 編譯，TUI 使用
從原始碼重建的 bionic `libopentui.so`——沒有 wrapper、沒有 proot、不依賴 musl。

不同版本會互相取代，請選定一條線。

## 本批次打通的建置問題

- **vite 8 原生綁定被剪**：`bun install --os=linux` 會重新解析整棵樹並剪掉
  android-only 的 optional 依賴（`rolldown`、`lightningcss`、`@tailwindcss/oxide`），
  之後 web UI 建置報 `Cannot find native binding`。現在依 `bun.lock` 中
  `{os:android,cpu:arm64}` 的條目直接取 tarball 補回。
- **平台套件安裝方式**：單一套件改為直接從 registry 取得，不再為每個套件跑一次
  完整的 `bun install`（先前每次卡在 10 分鐘逾時）。
- **PTY 套件改名**：上游將 `@opencode-ai/pty` 改名為 `@opencode/pty`（2.2.2 移除、
  2.2.3 以新名回歸）。套件名現在由版本矩陣解析，不再硬編碼。
- **opentui 0.8.0 補丁錨點**：原生資產目標移入 `getCurrentNodeAssetTarget()`，
  上游已寫死 `platform: "linux"`；補丁步驟改為驗證此性質，而非在舊錨點報錯。

## 驗收

本批每一版都在參考機（Android 9 / kernel `3.18.140-mokee` / aarch64）通過同一組判據：

`安裝 → --version → serve HTTP 200 → TUI 畫面 → 鍵入回顯 → 15 秒存活 → 無崩潰/降級標記`

`2.2.0`–`2.2.5` 於 2026-11-03 為本批次複驗；其餘版本在其建置輪次已於同機驗收。
每個套件另過 `make verify-artifact`（執行時二進位含 seccomp shim、v2 含內嵌 web UI），
上傳後的 digest 與 `SHA256SUMS.txt` 逐條一致。

## 已知問題

- **v2 與 `opencode1` 並存安裝**時，共用的 seccomp shim 路徑可能仍需
  `dpkg --force-overwrite`。
- `2.2.5` 首屏會顯示 `8 plugins failed`——外掛相容性告警，不是崩潰，TUI、`serve`
  與鍵入皆不受影響。
- 本批只發 **native** 家族；compressed（UPX）與 wrapper 不在其中。

安裝：`pacman -U ./opencode-2.2.5-1-aarch64.pkg.tar.xz` 或
`dpkg -i ./opencode_2.2.5_aarch64.deb`；校驗：`sha256sum -c SHA256SUMS.txt`。
